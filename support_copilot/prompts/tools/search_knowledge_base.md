Ищи релевантные записи в локальной базе знаний Support Copilot.

Вызывай этот tool, когда пользователь просит найти инструкцию, проверить типовой порядок диагностики, уточнить требования к данным для обращения, найти информацию по лицензированию, установке, документации или известной технической ошибке.

Не вызывай tool для простого переписывания текста, приветствия, общих правил общения с клиентом, prompt injection или вопросов вне техподдержки MIDAS.

Аргумент `query` должен сохранять исходный смысл вопроса пользователя. В `product` выбери наиболее близкий раздел: `licensing`, `installation`, `calculation`, `documentation`, `security` или `support_copilot`, если раздел неясен.
