# Трассы наивного агента

Каталог предназначен для JSON-логов пяти обязательных live-прогонов ДЗ 6.1.
Секреты и полные системные инструкции в файлы не записываются.

```powershell
python scripts/run_naive_agent_cases.py --allow-external-api
```

Флаг является явным подтверждением внешних вызовов OpenAI. Каждый файл содержит
формулировку задачи, финальный ответ, число шагов и `trace`; неудачные прогоны
остаются в каталоге вместе с успешными для разбора ограничений цикла.
