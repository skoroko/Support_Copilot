# Живое сравнение проверяемого обзора HSS

Дата: 16.10.2026. Пользователь разрешил платные API-вызовы и обновление
рабочего бота при подтверждении ускорения без потери качества.

## Протокол до первого вызова

Runner: `scripts/compare_verified_overview.py`. Три самостоятельных явных
HSS-вопроса: обычная формулировка, точное название из CHM и самостоятельный
обзор после обсуждения базовой HS. По три повтора на каждой ветке: 18 ответов,
девять пар. Порядок веток чередуется; параллельных запросов нет. Примеры
синтетические, реальных пользовательских переписок в этом эксперименте нет.

Обе ветки используют один кандидатный Docker-образ и одинаковые настройки
рабочего backend: `gpt-6-luna`, Responses API, medium, service tier `default`,
500 токенов целевого ответа и общий generation cap 8 692 с reasoning reserve.
Меняется только флаг пилота вместе с управляемым им слоем `evidence_scope`.
Обычная ветка — обычный граф **того же кандидатного кода**, не исторические
замеры и не прежний образ рабочего бота.

Отсчёт — от входа в граф до готового ответа. Импорт, построение RAG и прогрев
локального tokenizer исключены; поиск, embeddings, извлечение CHM, проверки
scope, вызовы модели и обработка ответа включены. Каждый ответ выполняется в
новом изолированном контейнере. Это консервативная проверка без постоянно
прогретого process-level CHM cache. Новая БД/checkpoints не создаются: граф
использует InMemorySaver; ingest и отправка Telegram выключены. Действующие
контейнеры продолжают работать во время сравнения.

Условия допуска к обновлению:

- медиана пилота минимум на 20% ниже, он быстрее в семи из девяти пар;
- каждый пилотный ответ действительно проходит `verified`, один model call;
- все четыре обязательных аспекта есть в каждом ответе: HSS/Modified
  Mohr–Coulomb/overlay, поведение жёсткости, три E-модуля с различимыми
  определениями, G0ref/γ0.7 с правильным смыслом;
- ни одной существенной ошибки или неподтверждённого технического утверждения;
- точные процитированные фрагменты подтверждают утверждения, включая вариант
  модели; полнота не хуже соответствующего обычного ответа;
- неудачные результаты сохраняются, не заменяются успешными попытками.

Дополнительная полнота оценивается отдельно: очень узкий действительно упругий
диапазон, зависимость жёсткости от напряжений (`m`), соотношение
Хардина–Дрневича. Это узкий краткий обзор HSS, не проверка остальных сценариев
и не подтверждение SLA 10–15 секунд.

Полные ответы, исходные evidence и manifest с SHA-256 остаются в ignored
`var/verified_overview_live/`. При проверке ссылок учитывается перенумерация
`ground_answer`: видимый marker → `answer.sources` → `chunk_id` → полный
`citation_evidence.text`. Номер из состояния графа нельзя напрямую подставлять
в уже обработанный ответ. Заголовок CHM подтверждает принадлежность разделу,
но не заменяет содержание цитаты.

## Результаты

### Первая серия

Все девять пилотных прогонов перешли в `fallback_insufficient_evidence`:
общие запросы описания/параметров находили описание HSS, но не её E-таблицу.
Exact scope не ослаблялся. Результат — два model calls и три retrieval вместо
двух calls и одного retrieval у обычной ветки.

- Обычная ветка: 8/9 ответов завершены, медиана успешных 8,718 с
  (7,961–11,635). Один `OpenAIConnectionError`, сохранён без повторной попытки;
  usage неудачного вызова неизвестен и не объявляется нулевым.
- Пилот: 9/9 завершены, медиана 11,063 с (8,422–11,942), на 26,9% медленнее.
  Быстрее только в одной из восьми завершённых пар.
- Пилот: факты и точные цитаты 9/9; обычная ветка: 7/8. В одном обычном ответе
  именованная основа Modified Mohr–Coulomb заменена на Mohr–Coulomb, вопреки
  процитированному тексту. Никакой ответ не содержал требуемых E-определений.
- Рабочий бот не обновлялся. Эта серия **не проверила качество tool-free
  generation**, поскольку проверяемая ветка ни разу не сработала.

Публичные данные: [live_v1.json](../tests/eval/results/2026-10-16_verified_overview/live_v1.json).

### Ограниченная правка и новая серия

Отдельный поисковый probe с E50ref/Eoedref/Eurref нашёл два собственных CHM
chunk HSS: описание и таблицу. Их полное содержимое, scope и SHA сохранены;
один этот поиск удовлетворяет исходному контракту. Дополнительной генерации
в probe нет; embeddings API использован с разрешения пользователя.

`focused_verified_plan` меняет первый запрос пилота на проверенный точный
запрос, второй оставляет для недостающего описания. Scope, версия, confidence,
проверка покрытия после бюджета и безопасный fallback сохранены. Формат
пилотного ответа уточнён: короткий вводный абзац и пять отдельных определений,
чтобы обязательные параметры не терялись из-за общего указания краткости.
Настройки runtime-модели и generation cap прежние.

V2 — **новая серия целиком**, с новыми обычными ответами на том же V2-коде,
а не сравнение с лучшими историческими временами. Те же 18 слотов, порядок,
рубрика и пороги выпуска зафиксированы до первого V2-вызова. Первая серия
сохранена неизменной; snapshots её изменённых исходников/runner лежат в
приватном каталоге, исходный образ сохранён отдельным тегом.

Целевые regression после правки: **86 passed, 1 skipped**. Финальный полный
regression: **944 passed, 12 skipped**, 151,06 с. Ruff проверенных pilot/
provenance/graph и evaluation scripts — PASS; прежние 13 диагностик `rag.py`
отмечены в отчёте первого этапа, новых нет. `git diff --check` — PASS.
Независимое структурное ревью — PASS.

Нулевая полная покрытость обычных ответов означает отсутствие E-определений
из зафиксированной рубрики, а не отсутствие полезного обзора вообще. Ошибка
цитирования ordinary slot 3: основа с Small strain overlay указана верно, но
ссылка ведёт на PDF-фрагмент, который overlay не называет. Другой найденный
CHM-фрагмент подтверждает этот факт, однако к соответствующей клаузе он не
привязан. Пилотных ошибок по точным фрагментам не найдено.

Пилот сработал в 9/9 случаях, сохранил все обязательные и дополнительные
аспекты относительно каждой пары; все ответы завершены без truncation.
**Ускорение не подтверждено:** медиана пилота выше на **11,48%**, быстрее он
только в **4/9 пар**. Условия выпуска (−20% медианы, минимум 7/9 более быстрых
пар) не выполнены. **Рабочий бот не обновлён; флаг пилота остаётся выключенным.**

Медиана суммы model time на ответ: 8,173 → 8,639 с; retrieval: 1,756 → 2,031 с.
Медиана суммарных входных токенов генерации уменьшилась 6 496 → 4 348, но
reasoning вырос 233 → 464 токена. Один model call и меньший контекст сами по
себе не обеспечили меньшую задержку на живой модели. Медианы компонентов
не обязаны складываться в медиану общего времени. Причинный вклад reasoning
без дополнительного контролируемого эксперимента не доказан.

Публичные данные: [live_v2.json](../tests/eval/results/2026-10-16_verified_overview/live_v2.json).
Оба JSON содержат все слоты, usage, decomposition, ручные оценки, парные
сравнения, исходный protocol/code SHA и идентификатор кандидатного образа.
Всего выполнено 36 попыток ответа, 35 завершены; 62 попытки вызова агентной модели,
включая один connection failure первой серии. Embedding-вызовы выполнялись
внутри retrieval и отдельного probe; их токены не входят в generation usage.
Денежную стоимость неизвестного неудачного вызова не объявляем нулевой.

Три близких HSS-формулировки не доказывают пригодность для базовой HS,
граничных условий, сравнения моделей, процедур, RAG API или полной Telegram
задержки. Диапазон менее 15 с в девяти успешных V2-пилотах не является SLA.

## Воспроизведение

Все команды выполняются из корня кода. Runner запрещает повторное выполнение
уже использованного слота и проверяет SHA manifest перед каждым вызовом.
Полные private inputs нужны только для повторного offline aggregation:

```powershell
.venv/Scripts/python.exe -X utf8 scripts/summarize_verified_overview.py --private var/verified_overview_live_v2 --output tests/eval/results/2026-10-16_verified_overview/live_v2.json
.venv/Scripts/python.exe -X utf8 scripts/check_deployment_source.py
.venv/Scripts/python.exe -X utf8 -m pytest tests
```

Живая серия выполнялась через `docker compose -f compose.yaml -f compose.luna.yaml
-f var/verified_overview_live_v2/eval.compose.yaml run --rm --no-deps -T` с
read-only mount `scripts:/app/scripts`, командой
`python scripts/compare_verified_overview.py <slot> --allow-paid-api --run-id verified_overview_live_v2`.
Образ V2: `llm-service:verified-overview-v2-20261016`,
SHA `3ae2943aec6384c18c01c87f6fabf50b2b2fdd93046677c51a272fc04f1afefe`.
