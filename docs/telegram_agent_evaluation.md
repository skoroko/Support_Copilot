## Качество

Codex и два read-only пакета Sol High проверили финальные [N] → sources[N-1] → chunk_id → точный сохранённый текст текущего вопроса. Для expanded использованы сохранённые evidence, без нового поиска или judge API. Шкала прежняя: correctness/completeness 1 — существенный эталон полон и верен, 0.5 — существенный пропуск/небольшая ошибка, 0 — неверное ядро/нет ответа. Grounding 1 — материальные утверждения подтверждены своими цитатами, 0.5 — небольшая неподтверждённая деталь, 0 — существенная подмена. Отказы без фактов получают grounding=null; свободный отказ с фактами оценивается.
