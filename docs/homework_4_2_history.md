# История учебного FSM ДЗ 4.2

Учебный `/ask` существовал до свободного диалога текущей версии. В Git
`1432e998dafea8ab0d7ae8b11f96563dd988537a` от 04.09.2026 сохранены
`bot/states.py` и `bot/handlers/fsm.py`. Это проверяемый снимок истории;
дата первого появления FSM этим документом не устанавливается.

Фактический путь: `/ask` → `waiting_for_topic` → выбор темы →
`waiting_for_question` → вопрос с выбранной темой в backend → очистка state.
При выборе отмены state очищается без backend-запроса. `confirming` объявлен
в классе состояний, но в этом снимке не используется; трёхшаговый сценарий
подтверждения не заявляется.

Точные байты двух исходных файлов экспортированы как текст, чтобы доказательство
читалось в ZIP без `.git`:

- [states.py.txt](../homework_4_2/historical/states.py.txt);
- [fsm.py.txt](../homework_4_2/historical/fsm.py.txt);
- [commit и SHA-256](../homework_4_2/historical/manifest.json).

Коммит `b068dc78db68adc5043e865bcea88d46f2927654` от 25.09.2026 удалил `/ask`
FSM. Текущий Telegram использует свободный ввод и меню; `/ask` не является
действующей командой. Экспорт не подключён к приложению и не восстанавливает
устаревший интерфейс. Это историческое доказательство реализации, не новый
live-запуск FSM. Текущий пользовательский сценарий принят отдельно:
[протокол](final_acceptance.md).
