## Проверяемая привязка

При включённом флаге `RAGService` добавляет к выбранному источнику
`evidence_scope`. Это ленивый структурный слой поверх прежних `chunk_id`:
векторная коллекция, embeddings и исходные chunks не изменяются.

- Точный вариант берётся из единственного HTML `title` исходного CHM-раздела.
  Совпадение слов внутри таблицы или пользовательского вопроса его не заменяет.
- Исходный chunk должен иметь единственное вхождение в нормализованном тексте
  этого раздела. Сохраняются `chunk_id`, SHA-256 исходного chunk и его диапазон.
- `title_anchor` хранит исходный заголовок и SHA-256 байтов CHM member;
  `chm_member` и `section_path` являются адресом источника. Заголовок не
  дописывается к старой цитате. Её окончательный текст имеет отдельный SHA-256.
- `product` и версия берутся из явных метаданных. `version=unknown` остаётся
  неизвестной; год в имени файла не объявляется версией продукта.
  Применимость не угадывается и остаётся `None`.
- PDF пока имеет `status=unknown`: наследование заголовков предыдущих страниц
  в этот инкремент не входит. Неизвестные и противоречащие заголовки подразделов,
  неоднозначные архивы, несовпадающие chunks и изменившиеся проекции отвергаются.

Извлечение CHM и проверка scope используют один ключ кеша с mtime, ctime,
inode и размером файла. Проверяется также соответствие предъявленного текста
текущей проекции из тех же байтов, которые подтверждают заголовок. Regression
покрывает замену архива с теми же размером/mtime и иным расположением ячеек.
Парсинг кеширует неизменяемые значения; инвентарь архивов разделяется внутри
одного retrieval, без постоянного глобального снимка корпуса.

## Путь ответа

```text
Явный обзор HSS → прежний gated retrieval → точная привязка и отбор
→ проверка описания/основы, E-модулей, G0ref/γ0.7 после ограничения контекста
→ один model call с tool_choice=none → прежние проверки ответа и citations
```

Сначала выполняется один поиск. Второй аспект запрашивается только при
недостаточном пакете. Итоговый пакет ограничен 8 000 символами, без обрезки
строк таблиц; одинаковые выдержки одного варианта/версии удаляются. Проверки
покрытия — узкий входной контракт, не автоматическое доказательство точности
будущего ответа. Разные известные версии и смесь известной/неизвестной версии
не объединяются в быстрый пакет.

Базовая HS, граничные условия, сравнения, действия, другой продукт/версия и
контекстные продолжения сразу используют обычный граф. Для них нет
спекулятивного prefetch. Если в пилотном HSS retrieval недостаточно проверяемых
материалов, сохраняется обычный агентный путь; лишние поиски этого случая
учитываются как fallback, а не успешное ускорение. Неполный пакет не передаётся
как основание для обязательного ответа без инструментов.

`agent_verified_overview_route` сообщает выбор ветки, причины fallback,
число поисков, отклонённых источников и время подготовки без текста запроса.
`agent_model_usage.response_path` различает обычный/пилотный/подробный ответ;
`total_output_cap` показывает общий предел вместе с reasoning reserve.
Неожиданные tools в пилоте отклоняются без выполнения и дополнительных model
calls. «Подробнее» использует прежний отдельный сценарий и сохранённые evidence.
История, grounding, обработка незавершённого ответа и Telegram approval сохранены.

## Проверка

- Целевые scope/graph/CHM contracts: **82 passed, 1 skipped** (Windows symlink).
- Полный regression: **944 passed, 12 skipped**, 175,56 с.
- Ruff изменённых/новых файлов — PASS. В `rag.py` те же 13 прежних
  замечаний, что в `HEAD`; новых диагностик нет. `git diff --check` — PASS.
- Replay реальных сохранённых chunks и исходного CHM: **PASS**, два набора.
  Пилот оставил два фрагмента, 3 685 символов вместо 9 593; тексты выдержек
  неизменны, citations последовательны. В сценарной модели 2 → 1 model calls.
- [offline.json](../tests/eval/results/2026-10-16_verified_overview/offline.json)
  содержит контрольные суммы исходных наборов и проверенного кода.
- Независимое ревью нашло рассогласование CHM cache keys; исправление и
  regression включены в результат.

Replay использует **производный явный HSS-вопрос**, старые поисковые выдачи и
сценарную модель. Это не проверка recall новых запросов, качества настоящего
ответа, скорости провайдера или достижения 10–15 секунд. Сетевых и платных
модельных вызовов в replay нет. Пилот остаётся выключенным до отдельной живой
проверки точности, полноты, цитат и общей задержки.

Воспроизведение из корня кода, с проектным Python 3.13:

```powershell
.venv/Scripts/python.exe -X utf8 scripts/check_deployment_source.py
.venv/Scripts/python.exe -X utf8 scripts/replay_verified_overview.py
.venv/Scripts/python.exe -m pytest tests
```

Приватные frozen inputs должны уже находиться в `var/`; runner не получает
их из сети и не включает вопросы/ответы/мануалы в публичный JSON. На Windows
sandbox блокировал асинхронный тестовый прогон; проверки графа выполнялись вне
sandbox с проектным Python, временные файлы — внутри `var/`.

Топология семи LangGraph-узлов, публичные API schemas и DB migrations не
менялись. Новый выбор находится внутри прежнего `prefetch_overview`.

Самостоятельные контракты для базовой HS и классификации границ остаются
будущим инкрементом. Перенос HSS-свойств на HS ради расширения пилота не допускается.
