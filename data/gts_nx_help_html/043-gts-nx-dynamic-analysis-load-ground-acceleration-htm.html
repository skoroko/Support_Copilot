Ground Acceleration Home > GTS NX > Dynamic Analysis > Load > Ground Acceleration Ground Acceleration (Ускорение основания) ▒ Обзор Загрузите функцию времени для нестационарного расчета с использованием данных об ускорениях основания. В нестационарном расчете динамические свойства сооружения и заданные нагрузки используются для расчете поведения сооружения (перемещения, усилия в элементах и т. п.) в произвольный момент времени при динамическом нагружении. Нестационарный расчет может быть выполнен методом суперпозиции форм (Mode Superposition Method) или методом прямого интегрирования (Direct Integration Method); подробная информация о задании демпфирования для каждого из методов расчета содержится в диалоговом окне [Настройки расчета] (Analysis Control). ▒ Методология [Direction] (Направление) Задайте направление ускорения основания. Ускорение основания может быть задано в виде комплекта нагрузок — одновременно по нескольким направлениям (X, Y, Z) в глобальной системе координат (GCS). Для значений ускорений основания может быть задан масштабный коэффициент, а также может быть указано время начала действия нагрузки. [Function] (Функция) Нажмите кнопку , чтобы задать функцию ускорений основания. Add time function (Добавить функцию времени) Задайте переменную во времени нагрузку путем прямого указания ряда моментов времени и соответствующих им значений нагрузки в табличном виде в левой части диалогового окна. В виде функций времени могут быть заданы следующие нагрузки: ускорения, сосредоточенные силы, моменты, нормализованные ускорения (функции ускорений во времени, ускорение гравитации) или нормальные ускорения (обобщенные). При смене формата данных изменяется только формат приложения нагрузки. Масштабный коэффициент представляет собой модуль градиента заданных данных. Весь набор данных может быть масштабирован для соответствия заданному максимальному значению. Задание нагрузки, являющейся функцией времени Функция времени также может быть определена для таких типов нагрузок, как динамическая нагрузка в узле (на поверхности) (Dynamic nodal (surface)) и переменная во времени статическая нагрузка (Time varying static). При необходимости задания сосредоточенной силы или момента используется опция задания динамической нагрузки в узле (на поверхности) (Dynamic nodal (surface)), а задание ускорений основания осуществляется с помощью опций задания ускорений (Acceleration) или нормализованный ускорений (Normalized acceleration). При использовании опции нормальности (Normal) переменная во времени нагрузка используется как переменная во времени статическая нагрузка (Time Varying Static) или динамическая нагрузка по поверхности (Dynamic surface). Import/Earthquake waves (Импорт данных о землетрясениях) Вы можете сохранять и импортировать часто используемые переменные во времени нагрузки, или выбрать данные исторических землетрясений из встроенной в программу базы данных. В базе данных программы содержится 32 записи данных исторических землетрясений. Add Time sinusoidal (Задание нагрузки как синусоидальной функции времени) Для задания нагрузки как функции времени может быть использована синусоидальная зависимость. В данной зависимости величины А и С являются константами, величина f – частота действия заданной нагрузки, D – коэффициент демпфирования, а Р – фазовый угол. Если переменная во времени нагрузка задается в виде гармонической функции, задайте необходимые переменные и нажмите кнопку [Обновить график] (Redraw Graph), чтобы отобразить график функции нагрузки в правой части диалогового окна.
