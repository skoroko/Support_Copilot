General Home > GTS NX > Analysis > Analysis Case > General > General General (Общие положения) ▒ Обзор Особенности расчетов основания удобнее рассматривать в сравнении с общими расчетами сооружений. В расчетах сооружений значительную роль играют неопределенности действующих нагрузок. Отдельные элементы конструкций проектируются на действие наибольших усилий в этих элементах, полученных из рассмотрения различных сочетаний нагрузок. В противоположность этому расчеты оснований сосредоточены больше на неопределенности этапов строительства и свойств материалов, чем на неопределенностях нагрузок, то есть важно понимать физическое состояние массива основания. В итоге, в расчетах оснований следует использовать твердотельные элементы для отображения реальных форм массива основания и этапов строительства; также должно учитываться нелинейное анизотропное поведение материалов основания и естественные напряжения в массиве, с тем, чтобы условия площадки строительства моделировались как можно ближе к реальным условиям. Программа, позволяющая выполнять расчеты оснований, может быть использована для моделирования естественных напряжений и оценки проектных и строительных решений. К расчетам оснований относятся различные типы расчетов, от общего статического расчета до расчетов фильтрации, сопряженных расчетов напряженно-деформированного состояния и фильтрации, расчетов консолидации, расчетов поэтапности строительства, устойчивости откосов и т. д. Данный раздел содержит краткий обзор методов расчета и описания опций расчетов. Алгоритмы расчетов более подробно рассмотрены в Главе 5 Руководства по расчетам. В программе доступны следующие возможности расчетов оснований: Static Analysis (Статический расчет) Linear static analysis (Линейный статический расчет) Non-linear static analysis (Non-linear elastic or Elasto-plastic analysis) (Нелинейный статический расчет (нелинейно-упругий или упругопластический расчет)) Construction Stage Analysis (Расчет поэтапности строительства) Seepage Analysis (Расчет фильтрации) Steady State (Расчет установившейся фильтрации) Transient (Расчет неустановившейся фильтрации) Coupled Seepage-Stress Analysis (Сопряженный расчет напряженно-деформированного состояния и фильтрации) Seepage-Stress Sequential Analysis (Последовательный расчет фильтрации и напряженно-деформированного состояния) Consolidation Analysis (Расчет консолидации) Fully-coupled Seepage-Stress Analysis (Полностью сопряженный расчет фильтрации и напряженно-деформированного состояния) Dynamic Analysis (Динамический расчет) EigenValue Analysis (Расчет собственных форм) Response Spectrum Analysis (Расчет спектра реакции Linear Time History(Modal) (Линейный нестационарный (модальный) расчет) Linear Time History(Direct) (Линейный нестационарный (прямой) расчет) Nonlinear Time History Analysis (Нелинейный нестационарный расчет) 2D Equivalent Linear Analysis (Двухмерный эквивалентный линейный расчет) Slope Stability Analysis (Расчет устойчивости откоса) Strength Reduction Method (Метод редукции) Stress Analysis Method (Метод расчета напряжений) Dynamic-Slope Coupled Analysis (Сопряженный расчет — динамический и устойчивости откоса) ▒ Методология Создайте «Расчетный случай» (Analysis Case), чтобы выполнить расчет. На данном шаге выбирается метод и условия расчета (Комплект сеток (Mes hset), граничные условия (Boundary condition), загружения (Load condition) и т. д.) для каждого метода. Дополнительно для каждого метода расчета могут быть настроены дополнительные опции расчета и вывода результатов. В частности, для расчета поэтапности строительства расчет может быть выполнен с использованием пяти различных методов расчета, также указываются данные используемые в расчете. Могут быть настроены дополнительные опции расчета и вывода результатов, а также заданы несколько этапов строительства для повторных расчетов на единой модели с изменением условий расчетов. <Состояние стрительства - поддерживаемые методы расчета > Задайте Название (Title) (и Описание (Description)), чтобы индивидуализировать каждый расчетный случай, и укажите тип расчета. Модель для данного расчетного случая должна быть подготовлена с учетом выбранного типа расчета. В расчете участвуют не все комплекты расчета, а только активированные условия расчета (сетки, граничные условия, загружения) перенесенные в раздел активных комплектов (Active Sets). Поэтому пользователь может создать несколько расчетных случаев путем настройки условий расчета для одной и той же модели с последующим сравнением результатов. В частности, при выполнении линейного статического расчета может быть использована опция [Выполнить независимый расчет каждого загружения] для выполнения серии расчетов с последующим сравнением результатов. Для каждого типа решения (метода расчета) доступны тонкие настройки расчета (шаг по времени, контроль решения, контроль вывода). Каждый метод расчета имеет различные настройки, которые должны быть проверены перед созданием расчетного случая (Analysis Case). (Go to Analysis Control) (Перейти к настройкам расчета) Если в расчете используются все комплекты модели, используйте кнопку чтобы переместить все условия в раздел активных комплектов. Если используется только несколько определенных условий, используйте функцию перетаскивания, чтобы перенести выбранные комплекты в раздел активных комплектов. В расчетах поэтапности строительства, так как данные используемые для поэтапного расчета уже заданы, необходимо выбрать только комплекты, используемые для выполнения расчета.
