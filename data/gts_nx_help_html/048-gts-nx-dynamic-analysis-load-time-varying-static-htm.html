Time Varying Static Home > GTS NX > Dynamic Analysis > Load > Time Varying Static Time Varying Static (Переменная во времени статическая нагрузка) ▒ Обзор Использование предварительно заданной статической нагрузки для задания нагрузки как функции времени для использования в нестационарном расчете. Динамическая нагрузка задается как произведение статической нагрузки на величину функции времени для данной нагрузки. Используемая в данном случае функция времени для нагрузки является безразмерной величиной; при этом может быть использован только нормальный тип исторических данных. Данная функция является функцией замены, которая включает динамическую узловую нагрузку (по поверхности) (Dynamic nodal (surface)), созданную сочетанием статической нагрузки и функцией времени для данной нагрузки. ▒ Методология Выберите статическую нагрузку для использования в комплекте нагрузок. При использовании статической нагрузки место ее приложения, направление действия и размер уже определены, поэтому остается указать соответствующую функцию времени. Модуль градиента нагрузки может быть определен с помощью масштабного коэффициента; также может быть задано время появления нагрузки. Нажмите кнопку , чтобы добавить (выбрать) функцию времени для нагрузки. Такая функция может быть выбрана только при нормальном (Normal) типе данных функции времени (безразмерной величине функции). Задайте переменную во времени нагрузку путем прямого указания ряда моментов времени и соответствующих им значений коэффициента изменения нагрузки в табличном виде в левой части диалогового окна. В виде функций времени могут быть заданы следующие нагрузки: ускорения, сосредоточенные силы, моменты, нормализованные ускорения (функции ускорений во времени, ускорение гравитации) или нормальные ускорения (обобщенные). При смене формата данных изменяется только формат приложения нагрузки. Масштабный коэффициент представляет собой модуль градиента заданных данных. Весь набор данных может быть масштабирован для соответствия заданному максимальному значению.
