Transmitting Home > GTS NX > Dynamic Analysis > Boundary > Transmitting Transmitting (Излучающая граница) ▒ Обзор Приближенное представление полу-бесконечного слоя основания путем задания виртуальной поверхности скольжения перпендикулярно горизонтальным слоям основания. Данная функция используется для учета распространения волн в дальнюю зону основания. Граничное условие излучающей границы используется только для Двумерной эквивалентной линейной опции Динамических расчетов (Dynamic analysis > 2D Equivalent linear analysis). Граничные условия, используемые в расчетах основания, могут быть следующих типов: 1. [Element Boundary Condition] (Элементные граничные условия) 2. [Viscous Boundary Condition] (Вязкие граничные условия) 3. [Transmitting Boundary Condition] (Излучающие граничные условия) 1. Элементные граничные условия могут быть следующего вида: 1) свободная граница, по которой задаются нагрузки сейсмического отклика, и 2) защемленная граница, по которой задаются перемещения в области границы свободного поля. Элементные граничные условия могут учитывать эффекты сейсмических волн в свободном поле, но они не учитывают эффекты волн, отраженных от фундамента существующего сооружения. Влияние данного эффекта возрастает по мере приближения точки границы к фундаменту сооружения. 2. Вязкие граничные условия были разработаны для устранения недостатков элементных граничных условий. Данные граничные условия разработаны Lysmer & Kuhlemeyer, Ang & Newmark позволяют поглощать волны, подходящие под определенным углом к границе. Однако, так как вязкие граничные условия не могут полностью отработать эффекты сложных поверхностных волн, то граница должна быть расположена на определенном расстоянии от фундамента сооружения, как и в случае использования элементных граничных условий. 3. Излучающие граничные условия устраняют недостатки вязких граничных условий и учитывают эффекты почти всех внутренних и поверхностных волн. Горизонтальный слой грунта может быть представлен в виде пружины и демпфера с использованием функции частоты. В излучающих граничных условиях обычно считается, что горизонтальные свойства каждого слоя грунта равны, и поэтому удовлетворительные результаты могут быть получены даже в случае, если граничные условия заданы на само сооружение. Однако для точного учета изменения свойств вследствие горизонтальных деформаций следует соблюдать определенное расстояние между границей основания и фундаментом сооружения. ▒ Методология Автоматическое создание излучающей границы для двухмерного линейного эквивалентного расчета General (Общие положения) Выберите ребро элемента и линию, чтобы задать по данному ребру элемента излучающее граничное условие. Свойства основания, присвоенные данному элементу, могут быть использованы для создания излучающей границы. Если выбрана линия между двумя элементами, то излучающая граница не может быть создана. Auto (Автоматически) При выборе комплекта сеток автоматически создаются граничные условия и элементы по левой/правой/нижней границах сеток, в соответствии с выбранными пользователем опциями Величина константы пружины вычисляется в зависимости от характеристик материала основания, заданных для комплекта сеток. Для левой/правой границы расчетной модели могут быть заданы излучающие граничные условия, а по нижней и свободной границах основания могут быть заданы вязкие граничные условия. Сложно выполнить точное моделирование основания, которое является почти бесконечным, с помощью двухмерной модели в расчетах сооружения совместно с основанием. Поэтому границы модели должны быть заданы на расстояниях, соответствующих инженерным критериям, а для основания должны быть определены естественные напряжения. Boundary Set (Комплект границ) Регистрация комплекта граничных условий для заданного комплекта границ.
