Boundary Table Import Export Home > GTS NX > Static,Slope Analysis > Boundary > Boundary Table Import Export Boundary Table Import Export ( Импорт/Экспорт данных по граничным условиям) - Обзор Импорт и экспорт данных по граничным условиям из файла/в файл в формате excel. Образец таблицы граничных условий (BoundaryTable Sample.xlsx) находится в папке установки (например, C:\Program Files\MIDAS\GTS NX\Sample) - Методология Данная функция имеет следующие ограничения: - Constraint (Ограничение): Программа поддерживает только "Расширенный" тип. Для отображения степеней свободы 'Tx-Rz' введите '1' (поставить флажок) или '0' (убрать флажок). - Nodal Head (Узловой напор): Выделяются типы "Полный" и "Давление". - Nodal Flux (Узловой поток): Экспортируется аналогично типу "Узловой напор". - Review (Обзор): Экспортируется только информация об узле.
