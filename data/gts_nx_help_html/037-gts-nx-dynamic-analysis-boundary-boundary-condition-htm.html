Constraint Home > GTS NX > Dynamic Analysis > Boundary > Constraint Constraint (Закрепления) ▒ Обзор Задание условий закрепления модели. ▒ Методология Автоматическое задание граничных условий нагрузки от собственного веса Доступны три метода задания условий закрепления для модели: [Базовый] (Basic), [Расширенный] (Advanced) и [Auto] (Автоматический). Basic (Базовый) Укажите цель и задайте закрепление в виде [Защемления] (Fixed), [Шарнирной опоры] или [Запрещения поворотов] (No Rotation), чтобы обозначить поведение модели. Advanced (Расширенный) С помощью данной функции могут быть полностью или частично запрещены 6 степеней свободы в узле. Tx, Ty, Tz представляют собой запрещения перемещений соответственно вдоль осей x, y, z, а Rx, Ry, Rz – запрещения поворотов относительно осей x, y, z. Условия закрепления могут быть заданы в соответствии с граничными условиями для точки (Point), ребра (Edge), грани (Face), узла (Node), узла на свободной грани (Free face node). Условия закрепления задаются на узлы элементов, и таким образом учитываются в расчете. Опция задания условий закрепления для точек, ребер, граней и т.п. представляет собой удобный способ выбора узлов с привязкой к геометрическим формам. Auto (Автоматический) Выберите целевой комплект сеток, чтобы автоматически задать условия закрепления. Условия закрепления основания для общего расчета напряженного состояния задаются автоматически. Перемещения по направлению x запрещаются по левой и правой границе, перемещения по направлению y – по передней и задней границе, а перемещения по x и y – по нижней границе модели. Boundary set (Комплект границ) Задание комплекта граничных условий для выбранного комплекта границ. При этом пользователь может задать имя комплекта границ. Симметричные и антисимметричные условия закрепления Можно обозначить два вида условий задания граничных условий; 1. Заданы условия закрепления для целевого объекта расчета. 2. Свойство симметрии конструкции используется для расчета только области симметрии, а не всей модели. Задание условия симметрии представляет собой весьма эффективный способ повышения эффективности моделирования и снижения времени расчета. Если геометрия модели и нагрузки симметричны, то для моделирования может быть использована ½ или ¼ модели, что позволяет уменьшить число элементов и сократить время счета. Однако такой подход имеет следующее ограничение: деформированная схема или схема распределения напряжений не может быть показана для полной модели, так как расчет выполняется только для области симметрии. Чтобы компенсировать данное ограничение, используйте функцию Просмотра симметричной модели (View symmetric model) из набора функций Дополнительных опций просмотра (Additional view control toolset), что позволяет развернуть результаты расчета ½ или ¼ модели на полную модель. Как задать граничные условия симметрии Если одна или несколько геометрических форм, материалов, нагрузок или граничных условий симметричны относительно плоскости или оси, то в расчете могут быть использованы граничные условия симметрии. Результаты, полученные при расчете ½, ¼, 1/8 части симметричной модели, могут быть развернуты на полную модель для удобства просмотра результатов расчета. Для задания условий симметрии граничные условия должны быть заданы таким образом, чтобы конструкция не нарушала плоскость симметрии. На представленном ниже рисунке показан пример задания граничных условий симметрии для твердотельной модели. Для задания граничных условий симметрии по плоскости YZ запрещается поступательная степень свободы Tx. Для плоскости XY должна быть запрещена степень свободы Tz, а для плоскости ZX – степень свободы Ty. Так как твердотельные элементы не обладают вращательными степенями свободы, то в граничных условиях симметричной модели запрещаются только поступательные степени свободы. Однако для оболочечных моделей должны быть запрещены вращательные степени свободы, чтобы обеспечить ненарушенность плоскости симметрии. Другими словами, для плоскости XY должны быть запрещены степени свободы Tx, Ry, Rz, для плоскости ZY – Tz, Rx, Ry, а для плоскости ZX – Ty, Rx, Rz. При задании граничных условий симметрии величины нагрузок должны быть скорректированы для удовлетворения условий симметрии. Также условия симметрии не могут быть использованы в расчетах собственных колебаний и устойчивости формы, так как такого рода расчеты требует рассмотрения несимметричных форм колебаний и форм потери устойчивости.
