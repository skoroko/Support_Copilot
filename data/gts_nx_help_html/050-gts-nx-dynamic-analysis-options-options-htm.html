Options Home > GTS NX > Dynamic Analysis > Options > Options Options (Опции) ▒ Обзор Выполните настройку общей среды программы. Настройки общей среды имеют следующие разделы: Общие (General), Геометрия/Разбивка/Связи (Geometry/Mesh/Connections), Нагрузки/Граничные условия (Loads/BoundaryCondition), Расчет/Результаты (Analysis/Results). ▒ Методология General (Общие) [General] (Общие настройки) Application (Приложение) : Укажите имя пользователя, название компании, папку временных файлов, интервал автосохранения, и т.п. License (Лицензия) : Авторизуйте лицензию программы. Поддерживаются локальный (StandAlone (USBHardlock)) и сетевой (Web) методы авторизации. Unit system (Система единиц измерения) : Укажите используемые в расчете единицы измерения силы/длины/времени. При необходимости перед началом Unitsystemили после выполнения расчета используйте конвертер величин в правом нижнем углу диалогового окна. [Graphic] (Настройки графики) Work View (Рабочий вид) : Выберите необходимые опции экрана. - Использование колеса прокрутки мыши может быть настроено для соответствия функциям прокрутки в 3DCAD. - Smoothing Surface Rendering (Метод сглаживания при рендеринге поверхностей) позволяет управлять тесселяцией криволинейных поверхностей. Доступны уровни сглаживания от 1 до 5, при этом больший уровень соответствует более высокому качеству отображения при лучшем их сглаживании. - The Shape of the Dynamic View (Форма динамического вида) является опцией отображения формы модели в рабочем окне при вращении модели. Selection (Выбор) : Укажите необходимые опции для частей (part) модели. Guider (Указатель) : Укажите необходимые опции для экранного указателя. Geometry shape (Геометрическая форма) : Укажите цвет для каждой геометрической формы. Element (Элемент) : Укажите цвет для каждого типа элемента . Advanced (Дополнительно) : Настройте дополнительные опции графики. В частности, опции отображения и настройки теней. Доступно несколько уровней теней – от 1 до 5, при этом более высокий уровень соответствует более темным теням. Geometry/Mesh/Connect (Геометрия/Конечно-элементная сеть/Связь) [Geometry] (Геометрия) Common (Общие настройки) : Настройка опций, используемых на всех геометрических формах . Import (Импорт) : Настройка опций импорта. [Mesh Set] (Настройки конечно-элементной сети) Common (Общие настройки) : Настройка опций, используемых на всех свойствах конечно-элементных сеток. Size Control (Управление размерами элементов) : Настройка цвета отображаемых символов при использовании функции начальной разбивки (seed function). Load/Boundary Condition (Нагрузки/Граничные условия) [Coordinate system] (Система координат) : Выбор цвета символа системы координат. Символ 1 (Symbol1), Символ 2 (Symbol2) и Символ 3 (Symbol3) соответствует обозначению оси X, Y и Z соответственно. [Mesh] (Конечно-элементная сеть) : Выбор размера символов номеров узлов и элементов. [Static load] (Статическая нагрузка) : Выбор размера и цвета символа статической нагрузки. [Dynamic load] (Динамическая нагрузка) : Выбор размера и цвета символа динамической нагрузки. [Boundary condition] (Граничные условия) : Выбор размера и цвета символов граничных условий. Analysis/Results (Расчет/Результаты) [Analysis] (Расчет) Number of processors (Количество процессоров) : Укажите число процессоров используемых для расчета. Для двухъядерных процессоров укажите число 2, для 4-ядерных – 4, чтобы увеличить скорость выполнения расчета. Element Formulation (Формулировка конечных элементов) : Укажите используемую формулировку конечных элементов. Между скоростью решения задачи и типом формулировки существует следующая зависимость: Редуцированная формулировка (Reduced) Скорость решения (Efficiency) > Стандартная формулировка (Standard) Устойчивость решения (Stability) > Смешанная формулировка (Hybrid) Точность решение (Accuracy). Equation Solver (Structural) (Решатель системы уравнений (задачи прочности)) : Выбор метода решения систем уравнений метода конечных элементов. Если активирована опция автоматического выбора, то программа автоматически выбирает один из следующих методов: мультифронтальный (Multifrontal), метод полностью заполненной матрицы (Dense matrix) или алгебраический многосеточный метод (AMG(Algebraic Multi-Grid)). 2D Element Setting (Structure) (Настройки двумерных элементов (прочностных)) : функция создания нормалей [UniqueShellNormalGeneration] рассматривает два смежных оболочечных элемента на предмет разнонаправленности их нормалей в случае, когда величина разницы между векторами нормалей больше заданной предельной величины. Так как размер элемента относительно больше кривизны оболочки, если данная величина увеличивается для случая грубо скругленной сетки, то может быть вычислен более гладкий контур, учитывающий кривизну геометрической формы. Опция учета степени свободы вращения [Consider Drilling DOF (degree of freedom)] вычисляет жесткость деформации в плоскости путем учета вращения вокруг внеплановой оси (степень свободы вращения). [Result] (Результаты) General (Общие) : Укажите значение результата расчета, которое является чрезвычайно малой величиной и может быть приравнено нулю. Значение по умолчанию равно 1e-12, т.е. результаты меньшие этой величины считаются равными нулю. Contour (Изополя) : Различные настройки представления результатов расчета в виде изополей. Vector (Вектор) : Настройка представления символов векторов для результатов, которые могут быть представлены в виде векторов. Deform (Деформации) : Базовые настройки отображения деформированной схемы сооружения по результатам расчета. No result entity (Элементы, не содержащие результатов) : Настройка отображения элементов, которые не содержат результатов, при просмотре результатов расчета. Diagram (Эпюры) : Базовые настройки отображения эпюр. Graph (График) : Настройки отображения графика. Animation (Анимация) : Укажите путь хранения файлов анимации. Legend (Шкала) : Укажите цвет фона и количество делений шкалы, отображаемой на экране. Customize Shortcut Key (Настройка горячих клавиш) Для наиболее часто используемых команд пользователь может определить горячие клавиши вызова.
