Artificial Earthquake Home > GTS NX > Dynamic Analysis > Tools > Artificial Earthquake Artificial Earthquake Generator (Генератор искусственного землетрясения) - Обзор Формирование данных искусственного землетрясения на основе встроенных расчетных спектральных данных. Огибающая функция (Envelope Function) позволяет формировать нестационарные данные для землетрясения. Существует три типа огибающих функций: трапецеидальная, составная и экспоненциальная. В GTS NX реализована поддержка функции трапецеидального типа. - Методология [Расчетные спектральные данные] [Процесс генерации искусственного землетрясения] где, ? n = частота, A n = амплитуда, Ф n = фазовый угол, и I(t) = огибающая функция [Огибающая функция] Огибающая функция умножается на стационарное движение для нестационарного настоящего сейсмического воздействия, и эта функция может быть разделена на три типа: трапецеидальную, составную и экспоненциальную. Без огибающей функции значение динамического ускорения будет практически одинаковым от начала до конца. Generate Options (Опции формирования) - Max Iterations (Максимум итераций): Максимальное число итераций до достижения вычисляемых спектральных данных целевых значений. - Max. Acceleration (Максимальное ускорение): Максимальное ускорение в синтезированных сейсмических данных - Damping Ratio (Коэффициент демпфирования): Коэффициент демпфирования для вычисления спектральных данных - Random Seed (Случайная начальная точка разбивки): определение случайной началььной точки разбивки для расчета спектра отклика искусственного землетрясения (искусственное положительное значение). Generate Acceleration (Сформировать ускорения): Convert from response spectrum to acceleration data (Преобразование спектра реакции в данные ускорений) - Spectrum Graph ( Спектральный график) : Проверка результатов на основе спектральных данных - Acceleration Graph ( График ускорений) : Проверка результатов на основе данных ускорений
