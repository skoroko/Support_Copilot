Model (Strata modeling) Home > GTS NX > Dynamic Analysis > Tools > Free Field Analysis > Model (Strata modeling) Model : Strata modeling (Модель: Редактирование слоев) ▒ Обзор Создание модели основания для расчета сводного поля. Задайте свойства материала грунта для каждого слоя основания. ▒ Методология <Редактирование слоев> Нажмите кнопку [Задать свойства материала грунта] (Input ground material property data), чтобы задать свойства материалов слоев основания. (Максимальное количество слоев ограничено значением 50). [Number] (Номер): Автоматически присвоенный идентификационный номер, начиная от 1. [Depth] (Глубина):Задайте глубину слоя. Значение глубины должно быть больше 0 и быть возрастающей величиной. При задании глубины автоматически вычисляется мощность слоя грунта. [Unit weight] (Удельный вес): Задайте удельный вес грунта в заданном слое. [Vs(m/sec)] : Задайте скорость поперечных волн в основании. [G0(kN/m2)] :Задайте максимальный модуль сдвига. [H0] : Задайте начальный коэффициент демпфирования для основания. [Output Motion type] (Результирующий тип колебаний) Outcropping (На поверхности основания) Задается для слоя, результаты расчета для которого определяются на поверхности. Within (В массиве) Задается для слоя, результаты расчета для которого определяются как реакция основания. [Dynamic Curve Function] (Функция динамической кривой) Нажмите кнопку для выбора или задания модуля сдвига и функции коэффициента демпфирования для учета нелинейного неупругого поведения основания. (Деформации сдвига определяются функцией динамических свойств материала).
