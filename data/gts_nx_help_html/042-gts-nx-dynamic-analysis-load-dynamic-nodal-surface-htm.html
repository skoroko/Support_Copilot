Dynamic Nodal (Surface) Home > GTS NX > Dynamic Analysis > Load > Dynamic Nodal (Surface) Dynamic Nodal (Surface) (Динамическая нагрузка по поверхности) ▒ Обзор Данный функционал используется для прямого создания функции времени для нагрузки для использования в нестационарном расчете. Статическая нагрузка и сила (давление) задаются с помощью функции времени. При создании функций времени для задания динамических узловых нагрузок могут быть использованы такие типы данных, как сила (Force), момент (Moments), и нормальный тип (Normal) — при задании динамических нагрузок по поверхности. В дополнение может быть использована функция привязки для описания линейно или нелинейно распределенных динамических нагрузок, величина которых меняется в зависимости от координат. Такие функции используются для задания нагрузок от вибраций, авто- и железнодорожного транспорта, взрывов. Также может быть задано время появления нагрузки. ▒ Методология Выберите узел, в котором будет приложена нагрузка, и укажите направление ее действия. Размер нагрузки определяется умножением величины функции времени (функция изменения размера функции во времени) на каждую из компонент нагрузки (масштабный коэффициент). [Object] (Объект) Задаваемая нагрузка действует в узле, но целевым объектом при задании нагрузки также может быть геометрическая форма (ребро, поверхность и т. д.), а также может быть использована функция автоматического выбора узлов на свободной грани. При использовании линии или поверхности такая форма прежде должна быть использована для создания элементов, нагрузка при этом задается во все узлы элементов формы с учетом заданного размера и направления. При использовании узлов на свободной грани следует выбрать такие узлы, при этом также автоматически будут выбраны все точки, которые расположены относительно содержащего данные узлы элемента в пределах угла, величина которого не превышает заданную. [Reference Object] (Объект привязки) Направление действия нагрузки может быть задано различными методами. По умолчанию направление нагрузки определяется в глобальной декартовой (цилиндрической) системе координат. В качестве объекта привязки для указания направления могут быть выбраны геометрические формы: ребра и поверхности. При выборе линии или поверхности отображается система координат выбранного объекта, и нагрузка задается в данной системе координат. Опция «Вектор» используется для задания нагрузки в соответствии с направлением компонент векторов X, Y, Z. [Components] (Компоненты) Задайте масштабный коэффициент для нагрузки с учетом ее направления. В общем случае размер нагрузки определен заранее как переменная во времени величина в функции времени, и если максимальное значение коэффициента равно 1, то в функции времени используется действительный размер нагрузки. При положительной величине нагрузки направление ее действия совпадает с направлением привязки, при отрицательном — нагрузка действует в противоположном направлении. Изменение размера нагрузки в зависимости от координат объекта ее приложения может быть описано в виде функции. При этом величина нагрузки умножается на величину такой функции. [Time Dependency (Time function)] (Зависимость от времени (Функция времени)) Задайте зависимость размера нагрузки от времени. Нажмите кнопку , чтобы добавить (выбрать) функции времени. Данная опция может быть использована только в случае, когда тип данных функции времени — сила (Force) или момент (Moments). Methodology (Dynamic Surface) (Методология (Динамическая нагрузка на поверхность)) Динамическая нагрузка на поверхность задается как распределенная нагрузка на ребро или грань элемента меняющаяся во времени. Такая нагрузка может быть задана на двухмерные или трехмерные элементы, а направление действия нагрузки может быть задано вдоль произвольной оси координат, произвольно направленного вектора, или по нормали. [Components] (Компоненты) Задайте масштабный коэффициент для нагрузки по заданному направлению. Нагрузка может быть задана равномерное или неравномерно (линейно или нелинейно) распределенной. При задании положительной (+) величины нагрузка действует в заданном направлении, а при отрицательной (-) - в направлении, противоположном заданному. Закон изменения размера нагрузки в зависимости от координат (относительно глобальной системы координат) может быть задан в виде функции. В этом случае величина нагрузки умножается на величину функции. [Time Dependency (Time function)] (Зависимость от времени (Функция времени)) Определите зависимость размера нагрузки от времени. Нажмите кнопку , чтобы добавить (выбрать) функцию времени для нагрузки. Такая функция может быть задана только для «нормального» (Normal) типа данных. «Нормальные» функции являются безразмерными, т. е. не имеют единиц измерения. Таким образом, если величина давления задана напрямую, то для компоненты нагрузки задается только масштабный коэффициент. Если максимальное значение коэффициента равно 1, то задается действительная величина нагрузки.
