Free Field Analysis(Starting) Home > GTS NX > Dynamic Analysis > Tools > Free Field Analysis > Free Field Analysis(Starting) Free Field Analysis(Starting) (Расчет свободного поля (Начальные сведения)) ▒ Обзор Одномерный расчет реакции основания (Ground Response Analysis), также называемый расчетом реакции площадки (Site Response Analysis) — модуль, используемый для расчета натурной реакции основания на сейсмические нагрузки до начала возведения или устройства выемки. Model (Strata modeling) (Модель (Редактирование слоев основания)) Model(Dynamic Curve Function) (Модель (Функция динамической кривой)) Model(Ground acceleration function) (Модель (Функция ускорения основания)) Earthquake Response Spectrum (Спектр реакции для земплетрясения) Analysis (Расчет) Result (Результат) ▒ Методология Сначала следует создать новый проект, а затем задать данные о слоях основания, свойства материалов, функции динамических свойств материалов и функцию ускорений основания. Затем необходимо сформировать расчетный случай и выполнить расчет для получения результатов. File (Файл) Задайте основные параметры проекта. Так как результаты расчета определяются параметрами, заданными во вкладке Настроек проекта (Project Setting), то настройки должны быть аккуратно заданы но начала расчета. Наилучшим подходом является установка необходимых настроек при запуске нового проекта, но допускается также изменение настроек в процессе работы над моделью. Задайте систему единиц, используемую в проекте. Нажмите кнопку [Преобразование единиц] для выбора необходимых размерностей. Размерность величины времени не может быть изменена. Edit (Редактировать) Вернуться в предыдущее состояние с помощью функции отмены (undo), или повторно выполнить заданное действие (redo).
