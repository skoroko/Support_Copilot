Result Home > GTS NX > Dynamic Analysis > Tools > Free Field Analysis > Result Result (Результат) ▒ Методология Результат Результаты расчета отображаются в табличном виде или в виде графика для каждого значения глубины. Результаты расчета и таблица (абсолютные значения) (Максимальное ускорение, максимальная скорость, максимальное перемещение) Результаты расчета и таблица (относительные значения) (Максимальное ускорение, максимальная скорость, максимальное перемещение) Таблица результатов для деформаций/напряжений (Равномерные деформации, максимальные деформации, максимальные деформации сдвига) Таблица результатов для сечения грунта (коэффициент демпфирования, модуль сдвига, коэффициент модуля сдвига) Таблица сечения грунта (скорость поперечной волны, модуль сдвига, коэффициент демпфирования) Result : Time History Result (Результаты : Результаты как функция времени) Выберите тип функции для отображения графика. Доступны следующие типы функций: перемещения основания, спектр реакции, напряжения/деформации, и передаточная функция. [Time History Result Function] (Функция зависимости результатов от времени) Выберите данные для функции, слой, тип результатов для отображения графика. Каждый тип результатов может быть выбран в зависимости от типа функции результатов расчета перемещений основания. Тип функции результатов расчета перемещений основания Тип результатов Перемещения основания Перемещение, скорость, ускорение, относительное перемещение, относительная скорость, относительное ускорение Спектр реакции Относительное перемещение, относительная псевдо-скорость, относительная скорость, абсолютное псевдо-ускорение, абсолютное ускорение Напряжения/деформации Напряжение, деформация Передаточная функция Передаточная функция Выбранная функция результатов привязывается к оси y. Название графика, название оси х и y могут быть определены для графика истории с помощью функции «Задать график» (Define Graph), величины также могут быть представлены в экспоненциальной форме. Шкалы по осям х и y также могут быть представлены в логарифмическом масштабе. Кроме того, в настройках графика (Graph Options) может быть использовано быстрое преобразование Фурье. Созданный график отображается в диалоговом окне и может быть экспортирован во множестве форматов, включая графический формат, файл word или файл excel.
