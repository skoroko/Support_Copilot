History Output Probes Home > GTS NX > Analysis > History > History Output Probes History Output Probes (Исследование истории результатов) - Обзор Данная операция позволяет указать функцию вывода результатов для определенной области модели в виде графика функции времени по итогам нестационарного расчета (нестационарный расчет фильтрации, консолидации, полностью сопряженный расчет напряженного состояния и фильтрации, линейный/нелинейный нестационарный расчет, двумерный эквивалентный расчет). Так как вывод всех результатов расчета в дереве результатов неэффективен как в плане удобства работы, так и производительности, то пользователь может указать желаемую область модели для отображения результатов. Другими словами, поисковый узел для просмотра результатов расчета как функции времени должен быть задан до выполнения расчета. - Методология Следующая последовательность действий позволяет вывести историю результатов в виде графика функции времени для всех типов нестационарных расчетов. Отображаемые в виде истории результаты включают в себя деформации основания, усилия в элементах и результаты расчетов фильтрации. 1. Выберите тип результата (Analysis (Расчет) > History (История результатов) > History Output Probes (Вывод элементов истории) > Probe Type (Тип результата)) и выберите объект для вывода результатов <Поиск по истории результатов и тип поиска> 1. Данная опция может быть использована для любого типа запросов, при этом может быть выбран конкретный компонент интересующей величины. Вывод элементных результатов может быть выполнен для центрального узла или для всех узлов элемента. Однако при этом не могут быть получены результаты для промежуточных узлов элементов высшего порядка. Для результатов типа Перемещение/Скорость/Ускорение результаты, вычисленные в [Узле привязки], могут быть использованы для вывода относительных результатов. В случае «Функции передачи» такие результаты всегда являются относительными, и пользователю необходимо указать [Узел привязки]. Опция [Шаг истории] позволяет указать шаг вывода результатов. Выберите [Выводить все шаги], чтобы вывести результаты для всех интервалов времени, а не только для шагов по времени для вывода, указанных в расчетном случае. Используйте опцию [Частота] (Frequency) для вывода результатов расчета выполненного с заданным числом шагов по времени / временным интервалом. Например, для расчетного случая, выполненного с интервалами по времени величиной 0.1, 0.2, 0.3 сек… и моментами времени для отображения промежуточных результатов 0.3, 0.6 сек…, при задании «Шаг : 2» вывод результатов будет выполнен для моментов времени 0.2, 0.4, 0.6 сек… При задании значения «0.2 сек» для опции «Время» (Time) результаты будут представлены для моментов времени 0.2, 0.4, 0.6 сек… ? Будьте внимательны, чтобы не указать моменты времени, результаты для которых не предусмотрены расчетным случаем. 2. Analysis (Расчет) > Analysis (Расчет) > General (Общие параметры) > Output control (Настройки вывода) > Register (Зарегистрировать) элементы истории для вывода результатов, добавленные из закладки истории <Настройки вывода истории результатов> 3. Result (Результаты) > Special Post (Особый запрос) > History (История результатов) > Check (Просмотр) результатов в виде графика функции времени <График поиска по истории результатов>
