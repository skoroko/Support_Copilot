Load to Mass Home > GTS NX > Dynamic Analysis > Load > Load to Mass Load to Mass (Приведение нагрузки к массе) ▒ Обзор Преобразование ранее заданной статической нагрузки в массу для учета в динамическом расчете — линейно-спектральном или нестационарном. ▒ Методология Приведение статической нагрузки (сосредоточенной силы, нагрузки на балочный элемент и давления) к массе Mass direction(Global Csys.) (Обнаружение массы (В глобальной системе координат)) Укажите компоненты направлений для учета в преобразованных массах. При выполнении расчета такое преобразование позволяет учесть сейсмические воздействия (линейно-спектральный расчет, нестационарный расчет с использованием данных о землетрясении), при этом обычно учитывается горизонтально направленные воздействия, и при выборе X или Y направления обычно игнорируется перпендикулярная компонента масс. Однако, при учете нагрузки от транспорта или расчете колебаний плиты преобладающую форму колебаний диктует направление действия силы гравитации, т. е. выбирается направление Z. Таким образом, учитываемое при преобразовании масс направление определяется требованиями расчета. Static Load Type for Converting (Тип преобразуемой статической нагрузки) Выберите статическую нагрузку для преобразования, и укажите данные для силы, нагрузки на балку или для давления — для выбранной статической нагрузки — для преобразования в массу. При преобразовании нагрузки в массу может быть учтен масштабный коэффициент, а также задается гравитационное ускорение.
