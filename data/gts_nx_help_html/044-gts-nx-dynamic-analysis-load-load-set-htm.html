Load Set Home > GTS NX > Dynamic Analysis > Load > Load Set Load Set (Комплект нагрузок) ▒ Обзор Комплект нагрузок может рассматриваться как один из видов комплектов объектов. Созданные комплекты нагрузок удобно использовать для упорядочения информации расчетной модели, так же как комплекты сеток, комплекты границы и т. п. При задании действующих нагрузок им могут быть присвоены индивидуальные имена. Если комплект нагрузок сформирован, то набор комплектов нагрузок с учетом соответствующих коэффициентов может быть использован для создания сочетаний нагрузок. ▒ Методология
