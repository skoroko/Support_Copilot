Arbitrary Load Home > GTS NX > Static.Slope Analysis > Load > Arbitrary Load Arbitrary Load (Произвольная нагрузка ) - Обзор GTS NX позволяет задать произвольную функцию загрузки, которая может применяться к произвольному местоположению / области независимо от привязки к узлам и / или элементам. - Методология [Тип] - [ Select Object ( s )] (Выбрать объект(ы)) : выбрать объект(ы): выберите объект, которому назначена произвольная нагрузка . - [ Elements ] (Элементы): выберите элементы автоматически или вручную. - [ Ref . CSys ] (Опорная система координат): выберите опорную систему координат при приложении нагрузки. - [ Base Function ] (Функция координат): выберите функцию приложения нагрузки. - X : введите значение в направлении X . (когда пользователь выбирает глобальную цилиндрическую систему координат, направление R ). - Y : Введите значение в направлении Y (когда пользователь выбирает глобальную цилиндрическую систему координат, направление ? ) - Z : Введите значение в направлении Z . - P 1 / P 2: введите значение начальной/конечной точки. -[Uniformly Distributed Load] (Равномерно распределённая нагрузка): когда пользователь хочет задать значение равномерно распределённой нагрузки .
