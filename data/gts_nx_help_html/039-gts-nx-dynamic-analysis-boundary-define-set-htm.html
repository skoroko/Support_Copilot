Define Set Home > GTS NX > Dynamic Analysis > Boundary > Define Set Define Set (Создание комплекта) ▒ Обзор Создание комплекта граничных условий. ▒ Методология Задайте имя, характеристику и нажмите кнопку [Добавить] (Add), чтобы создать комплект граничных условий. Комплект граничных условий может быть создан заранее, а имя каждого элемента комплекта может быть задано при его создании. Созданный комплект граничных условий автоматически регистрируется в рабочем дереве: Worktree (Рабочее дерево) >Analysis (Расчет) >Boundary Condition (Граничные условия), при этом флажковый переключатель позволяет скрыть или отобразить соответствующий комплект.
