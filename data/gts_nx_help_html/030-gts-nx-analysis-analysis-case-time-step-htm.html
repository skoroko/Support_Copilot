Time Step Home > GTS NX > Analysis > Analysis Case > Time Step Time Step (Шаг по времени) ▒ Обзор Шаг по времени задается для проверки результатов во времени в расчете консолидации, фильтрации (нестационарный), динамическом расчете (линейный, нелинейный нестационарный). Результаты расчета могут быть рассмотрены на каждом заданном интервале времени, по результатам динамического расчета также может быть построен график зависимости результирующей величины от времени. ▒ Методология Consolidation (singular) analysis, Stress seepage-Fully coupled – Loading/Sustain (Расчет консолидации, Полностью сопряженный расчет напряженного состояния и фильтрации – Нагрузка/Несущая способность) Укажите используемый шаг по времени и коэффициент нагружения. Расчет консолидации может быть выполнен с использованием опции «Несущая способность» (Sustain) без создания этапа строительства. Пользователь может отдельно определить время нагружения и разгрузки. В расчете используются все заданные нагрузки, включая собственный вес, в соответствии с заданным временем и коэффициентом нагружения. Расчет выполняется путем моделирования рассеяния избыточного порового давления в последующем этапе нагружения, в соответствии с данными о времени, после завершения расчета [Нагружения] (Loading). Из-за этого коэффициент нагружения в опции [Несущая способность] (Sustain) не может быть задан, и информация о времени добавляется до окончательного времени [Нагружения] (Loading). Construction stage consolidation analysis - Input time and load (Расчет консолидации с учетом этапов строительства – Задание времени и нагрузок) Для расчета консолидации время приложения нагрузки и характер распределения добавленной нагрузки могут быть заданы путем задания времени коэффициента нагружения. <Начальное состояни> <Задание нагрузки от насыпи> <Длительный период> <Initial state> <Embankment load application> <Sustained period> При использовании модифицированной модели Cam-clay в качестве модели материала должны быть определены естественные напряжения. Таким образом, для вычисления естественных напряжений должен быть выполнен расчет дренирования, при этом время приложения нагрузки не имеет смысла. Если задана дополнительная нагрузка, то она задается на определенный период времени, как показано на приведенном выше рисунке «Задание нагрузки на насыпь». На рисунке показана дополнительная нагрузка, заданная в 10 разных шагов в течение 10 дней. При этом сумма коэффициентов нагружения равна 1.0. После того, как насыпь завершена, остальной расчет может быть выполнен с учетом постоянного действия заданной нагрузки, без дополнительного ее увеличения. Время разгрузки определяется на приведенном выше рисунке как «период разгрузки». Из-за особенностей расчета консолидации начальное изменение напряжений происходит быстро. Поэтому первый шаг по времени следует задавать малым, с последующим постепенным увеличением шагов по времени, чтобы обеспечить хорошую сходимость и скорость счета. Seepage(Transient analysis) - Define time step (Расчет фильтрации (нестационарный) – Задание шага по времени) Укажите шаг по времени для выполнения расчета и сохранения результатов. В расчете используется величина функции времени для фильтрующей границы (тепловой поток, расход), которая соответствует настройкам шага по времени, в соответствии с которыми могут быть просмотрены результаты расчета. Величины за пределами диапазона времени для функции времени для фильтрующей границы могут быть автоматически определены с помощью линейной интерполяции. Dynamic analysis - Define time step (Динамический расчет – Задание шага по времени) Шаги по времени могут быть заданы с нерегулярным интервалом, при этом целевому шагу по времени может быть присвоено имя. Time Duration (Период времени): задайте интервал времени Time Increment (Приращение времени): задайте интервал времени, который будет использован в расчетах для заданного диапазона времени. Intermediate Output (Промежуточные результаты): задайте интервал времени для вывода результатов расчета. Результаты выводятся для каждого интервала времени. ※ Для каждого заданного интервала результаты выводятся в дереве результатов. Если вам необходимо вывести большое количество данных, это может потребовать значительного времени. Если ваш ПК оборудован небольшим количеством RAM, то может оказаться невозможным создать файл результатов. В соответствии с заданным шагом по времени, отображается общее количество прошедшего времени (общее количество времени, использованное для расчета в соответствии с шагом по времени), общее число шагов по времени (общее число шагов по времени, использованное в расчете).
