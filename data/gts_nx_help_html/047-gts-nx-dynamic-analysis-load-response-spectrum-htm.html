Response Spectrum Home > GTS NX > Dynamic Analysis > Load > Response Spectrum Response Spectrum (Спектр реакции) - Обзор Пользователь может задать функцию спектра реакции (спектральные данные) и направление действия динамической нагрузки для выполнения линейно-спектрального расчета. Линейно-спектральный расчет позволяет определить периоды собственных колебаний, угловую частоту собственных колебаний или частоту собственных колебаний при максимальном физическом отклике как функцию при заданной на сооружение динамической нагрузке. Такой расчет может быть определен как расчет спектра реакции в перемещениях, расчет спектра реакции в псевдо-скоростях или псевдо-ускорениях. Требования к нагрузкам и граничным условиям при выполнении линейно-спектрального расчета такие же, как при выполнении статических расчетов, но нагрузки при этом должны быть заданы в виде функций времени, а кроме того в расчете учитываются внутренние силы и силы демпфирования. Важными результатами линейно-спектрального расчета являются узловые перемещения, скорости, ускорения, а также силы и напряжения в элементах. Подробны пояснения относительно методов суммирования форм колебаний и методов задания настроек демпфирования для оценки максимальных значений физических величин (перемещений, напряжений, усилий в элементах и т. д.) приводятся в окне настроек расчета (Analysis Control Settings).. - Методология [Direction] (Направление) Задание направления действия динамической нагрузки, определяемой с помощью спектра реакции, относительно глобальной системы координат (ГСК), а также задание коэффициента преобразования периода (Period Modification Factor), который увеличивает значения периодов всех учитываемых форм собственных колебаний при задании собственных частот по результатам расчетов собственных форм. [Spectrum Function] ( Спектральная функция) Задание спектральной функции для использования в расчете. Нажмите кнопку чтобы задать спектральную функцию . Напрямую задайте период и спектральное значение в ячейки колонок, расположенных в левой части диалогового окна. Спектральная функция определяется в виде графика в координатах спектральных значений и периода. Величина спектральной функции для произвольного значения собственного периода определяет линейной интерполяцией. Таким образом, области, в которых резко меняется кривизна спектральной кривой рекомендуется делить на несколько сегментов с плотным расположением спектральных значений. Диапазон периодов спектральной функции должен включать все собственные периоды сооружения. Различают следующие типы спектральных данных: нормализованное ускорение (спектр ускорений, ускорение гравитации), ускорение, скорость и спектр перемещений. При изменении формата данных функции времени изменяется только формат задания нагрузок, но не формат данных. Масштабный коэффициент представляет собой модуль градиента введенных данных. Все данные могут быть масштабированы для соответствия заданному максимальному значению. В области задания коэффициента демпфирования (Damping Ratio) следует задать коэффициент демпфирования для использования в расчете. Если коэффициент демпфирования заданный для сооружения отличается до данного, то спектральные данные обрабатываются в соответствии с коэффициентом демпфирования сооружения.
