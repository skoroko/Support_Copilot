Define Set Home > GTS NX > Thermal Analysis > Load > Define Set Define Set (создать комбинацию) - Обзор Задать комплект температурной нагрузки. - Mетодология Введите название и технические характеристики и нажмите кнопку [Добавить], чтобы задать комплект температурной нагрузки. Данные могут задаваться предварительно; имя каждой температурной нагрузки может вводиться при ее создании. Сохраненный комплект температурных нагрузок автоматически сохраняется в меню Дерево проекта > Расчет > Температурная нагрузка; для отображения или скрытия комплекта используется флажковый переключатель.
