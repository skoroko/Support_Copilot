Seismic Data Generator Home > GTS NX > Dynamic Analysis > Tools > Seismic Data Generator Seismic Data Generator (Генератор сейсмических данных) ▒ Обзор Функция формирования данных о сейсмических ускорениях, сейсмического спектра реакции и расчетного спектра реакции с использованием встроенной в GTS NX базы данных сейсмических колебаний. ▒ Методология File (Файл) Сохранение данных различного вида, созданных в модуле SGS, экспорт или импорт существующих данных. Generate (Генерировать) Формирование данных о сейсмических ускорениях, сейсмического спектра реакции и расчетного спектра реакции с использованием встроенной в GTS NX базы данных сейсмических колебаний. Earthquake Record (Запись землетрясения) Отображение данных сейсмических колебаний в виде графика. Выберите набор данных сейсмических колебаний, задайте амплитуду и масштаб времени, и нажмите кнопку [ОК]. Сформированные данные представляют собой нормализованные ускорения. Шаг по времени при этом равен 0.02 секунды для северо-американских землетрясений, и 0.01 секунды — для японских землетрясений. Данные других землетрясений в виде файла *. dbs (база данных SGS) могут быть загружены после нажатия кнопки [Импорт] (Import). Earthquake Response Spectra (Спектр реакции землетрясения) Отображение спектра реакции землетрясения в виде графика, с использованием данных сейсмических колебаний из базы данных или заданных пользователем. 1. Выберите комплект данных сейсмических колебаний, задайте амплитуду и масштаб времени. Вы также можете импортировать данные сейсмических колебаний в виде файла *. dbs (база данных SGS) после нажатия кнопки [Импорт] (Import). 2. Задайте коэффициент демпфирования. Чтобы задать одновременно несколько графиков коэффициентов демпфирования, используйте кнопку [Добавить] (Add). 3. Задайте диапазон периодов и шаг сетки для графика периодов. 4. Выберите тип спектра. 5. Активируйте опцию [Логарифмический масштаб по оси Х] для установки логарифмического масштаба по оси Х. Design Response Spectra (Расчетный спектр реакции) Задание расчетного спектра реакции и отображение его в виде графика. Задайте в диалоговом окне данные, необходимые для формирования спектра, укажите диапазон периодов спектра и нажмите кнопку [ОК] для отображения графика. Option (Опции) Задайте различные опции для графика. Оси x и y графика могут быть отображены в логарифмическом масштабе. Также могут быть отображены деления на осях графика. Может быть настроена толщина линий графика и отредактировано название графика. View (Вид) Настройка скрытия/отображения панели инструментов или панели состояния. Также может быть отредактирована функция масштаба для графика, и координаты времени и частоты для графика. Zoom Out All (Отменить масштабирование) Возврат масштаба в исходное состояние. Чтобы увеличить фрагмент графика, обозначьте контур фрагмента кликом и протягиванием левой кнопкой мыши. С помощью клика правой кнопкой мыши можно вернуть график к исходному виду. Time<->Frequency (Время<->Частота) Преобразование размерности оси х из времени в частоту и обратно.
