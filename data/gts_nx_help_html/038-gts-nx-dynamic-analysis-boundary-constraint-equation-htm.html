Constraint Equation Home > GTS NX > Dynamic Analysis > Boundary > Constraint Equation Constraint Equation (Уравнения связи) ▒ Обзор Данная функция позволяет связать степени свободы, так что поведение заданного узла будет зависеть от поведения другого узла. ▒ Методология Привязка поведения одного узла к поведению другого узла. Необходимо выбрать главный узел, который будет определять перемещения другого узла, и указать связываемые степени свободы [Constrained Node/DOF]. Обозначения TX, TY, TZ представляют собой степени свободы для перемещений, а обозначения RX, RY, RZ – степени свободы для поворотов. Опция задания независимого узла и выбора степеней свободы (Independent Node/DOF) позволяет задать коэффициенты, применяемые к перемещениям независимого узла, для определения связываемых степеней свободы и взаимосвязи перемещений между связываемыми узлами. Boundary Set (Комплект границ) Регистрация комплекта граничных условий для заданного комплекта границ. При этом пользователь может указать имя комплекта границ. Характеристики поведения связанных узлов аналогичны поведению узлов с жесткой связью (Mesh>Element>Create>Other>Rigid link). Например, когда основной узел перемещается на определенное расстояние, то зависимый узел может быть связан с основным таким образом, что еще смещение будет в 2 раза большим. Уравнения связи могут использоваться для создания сложных взаимосвязей поведений двух и более узлов.
