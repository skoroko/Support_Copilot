Nonlinear time history analysis + SRM Home > GTS NX > Analysis > Analysis Case > General > Nonlinear time history analysis + SRM Solution Type (Тип решения) ▒ Nonlinear time history analysis + SRM (Нелинейный нестационарный расчет + расчет устойчивости откоса методом редукции) Коэффициент надежности, полученный для базового расчета устойчивости откоса с помощью метода редукции не может быть использован как коэффициент надежности для условий динамического нагружения. Это связано с тем, что откосы более узвязвыми для динамических нагрузок, таких как землетрясения. В состоянии динамического равновесия напряженное состояние основания обусловлено не только собственным весом, но также инерционной силой вызванной колебаниями. GTS NX позволяет выполнить такой расчет устойчивости откоса для состояния динамического равновесия. Расчет устойчивости откоса основана на методе редукции и может быть использован в двухмерных, осесимметричных и трехмерных задачах. Исходное время в нелинейном нестационарном расчете может определять напряженное сстояние основания как начальное для расчета устойчивости откоса.
