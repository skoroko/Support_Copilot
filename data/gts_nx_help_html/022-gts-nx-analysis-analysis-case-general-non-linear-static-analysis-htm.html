Non-linear static analysis Home > GTS NX > Analysis > Analysis Case > General > Non-linear static analysis Solution Type (Тип решения) ▒ Non-linear static analysis (Нелинейный статический расчет) Все физические явления включают в себя нелинейности. Поведение конструкций и оснований не является исключением. Нелинейный статический расчет используется для моделирования поведения основания с учетом такого нелинейного поведения, когда изменения системы во времени малы и могут быть проигнорированы. GTS NX позволяет учесть следующие нелинейности Нелинейность материала: Такая нелинейность имеет место, когда взаимосвязь напряжений и деформаций имеет нелинейный характер. Большинство грунтовых материалов проявляют такую нелинейность. Геометрическая нелинейность: Если взаимосвязь перемещений и деформаций имеет нелинейный характер, но предположение линейной работы более не применимо в случае больших перемещений или поворотов. Нелинейность нагрузок и граничных условий: Нелинейность, которая включает нелинейно поведения контакта, или нелинейность, вызванную изменением направления действия нагрузки в зависимости от деформации, вызванной действием нагрузки, такой как сосредоточенная сила. При расчетах в GTS NX могут быть учтены все перечисленные выше нелинейности. Выполнение нелинейного расчета для сложных нелинейный систем может занять длительное время из-за необходимости проведения пошаговых вычислений. Таким образом, для практических нужд учет отдельных необходимых нелинейностей позволяет получить достоверные результаты расчета при небольшом времени выполнения счета.
