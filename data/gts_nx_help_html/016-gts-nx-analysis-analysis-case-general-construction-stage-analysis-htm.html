Construction Stage Analysis Home > GTS NX > Analysis > Analysis Case > General > Construction Stage Analysis Solution Type (Тип решения) - Construction Stage Analysis (Расчет поэтапности строительства) Расчет поэтапности строительства может быть использован для моделирования процесса возведения основания с использованием численного расчета. Расчет поэтапности строительства состоит из набора этапов, при этом условия нагружения и граничных условия, также как и отдельные элементы могут быть убраны или добавлены на любом из этапов. Такие изменения граничных условий или условий нагружения учитываются в начале каждого этапа. В GTS NX могут быть использованы следующие расчетные функции при выполнении расчетов поэтапности строительства. Stress-Slope Analysis (Расчет напряженного состояния и устойчивости откоса) Расчет напряженного состоянии и устойчивости откоса в процессе строительства Seepage Analysis (Расчет фильтрации) Поэтапный расчет стационарной фильтрации, поэтапный расчет нестационарной фильтрации Stress-Seepage-Slope coupled analysis (Связный расчет напряженного состояния, фильтрации и устойчивости откоса) Последовательный расчет напряженного состояния, фильтрации, и расчет устойчивости откоса в процессе строительства Consolidation analysis (Расчет консолидации) Расчет консолидации с учетом изменения внешних условий и поэтапности возведения насыпи Fully-coupled Stress-Seepage analysis (Полностью связный расчет напряженного состояния и фильтрации) Полностью связный расчет напряженного состояния и нестационарной фильтрации Heat Transfer (Расчет теплопереноса) Стадийные расчет теплопередачи в станионарной и нестационарной постановке. Seepage-Thermal Stress (полусовмещенный расчет теплопереноса с учетом фильтрации) Пользователи могут выполнять термогидромеханический расчет. Thermal Stress (Термо-маханический расчет) Может быть проведено термомеханическое моделирование. Stress - Nonlinear Time History analysis (Нелинейный нестационарный расчет напряженного состояния) Пользователю доступно выполнение нелинейного динамического расчета учетом напряженного состояния основания, определенного не только с учетом собственного веса, но также поэтапности строительства (истории напряжений). В качестве последнего этапа может быть задан нелинейный нестационарный этап. При выполнении расчета с учетом поэтапности строительства могут быть использованы следующие расчетные функции. Добавление/удаление элемента Добавление/удаление собственного веса Изменение граничных условий Изменение свойств скальных материалов Определение коэффициента распределения нагрузки Пошаговое определение уровня грунтовых вод Расчет для дренированных и недренированных условий Инициализация перемещений Расчет напряженного состояния для начального этапа строительства (Учет условия К0) Рестарт Например, расчет поэтапности строительства туннеля включает следующие этапы. 1 Этап: Начальные напряжения в основании 2 Этап: Выемка 1-го этапа 3 Этап: Армирование обделки 1-го этапа + выемка 2-го этапа 4 Этап: Армирование обделки 2-го этапа + выемка 3-го этапа 5 Этап: Армирование обделки 3-го этапа + выемка 4-го этапа …… (Повтор) …… Первый этап используется для вычисления естественных напряжений в слоях грунта. Так как расчет напряженного состояния основания предполагает, что естественное напряженное состояние является начальным состоянием, то необходимо выполнить расчет естественного напряженного состояния. В GTS NX используется расчет на действие собственного веса для вычисления естественного напряженного состояния. Activate / Deactivate element (Активация/деактивация элемента) Величина естественных напряжений в элементе, активированный при выполнении расчете с учетом поэтапности строительства, по умолчанию равна нулю. Но если для элемента задана величина преднапряжений, то такая величина считается величиной естественных напряжений. Если задана нагрузка от собственного веса, то на активированный элемент будет действовать объемная сила собственного веса. Если для активированного элемента используется модифицированная модель материала Cam-Clay, то такой элемент имеет начальные линейно-упругие свойства, которые определены условиями нагружения и граничными условиями соответствующего этапа. Новые узлы будут активированы при активации элемента, при этом начальные перемещения узлов также равны нулю. Если элемент деактивирован на этапе строительства, и при этом не определен дополнительный коэффициент распределения нагрузки, то внутренние усилия такого деактивированного элемента более не учитываются. Напряжение в модели перераспределяются в соответствии с данным условием. Loading / Unloading of weight (Добавление/удаление собственного веса) На любом этапе строительства может быть добавлена или удалена любая нагрузка, при этом нагрузка с предыдущего этапа сохраняется, за исключением следующих случаев. Если элемент, на который действует нагрузка, деактивирован на данном этапе, то действующий на него собственный вес и приложенные внешние нагрузки также удаляются. WЕсли деактивируется узел, то также удаляется действующая на него нагрузка. Добавленная нагрузка суммируется с нагрузкой, заданной ранее на предыдущем этапе строительства. Граничные условия могут редактироваться по тем же правилам, при этом действуют те же правила и исключения. Load distribution factor (Коэффициент распределения нагрузки) Коэффициент распределения нагрузки используется в расчетах поэтапности строительства для упрощения моделирования. Коэффициент распределения нагрузки представляет собой численный метод расчета, который использует значение коэффициента распределения нагрузки для учета влияния удаления элемента на следующих после удаления этапах. Коэффициент распределения нагрузки может использоваться для упрощения трехмерных задач до двухмерных, или для масштабирования (уменьшения) этапа строительства в расчете на трехмерной модели. Например, если релаксация напряжений в размере 40%, 30% и 30% возникает на трех последовательных этапах, начиная с этапа выемки, определите этап выемки и активируйте опцию использования коэффициента распределения нагрузки для данного шага. Введите значения 0.4, 0.3 и 0.3 для коэффициента распределения нагрузки в окне опций для «Этап 0, 1, 2 после текущего этапа» соответственно. Material property conversion (Преобразование свойств материала) При расчете поэтапности строительства свойства материалов основания могут меняться для моделирования операций разработки или упрочнения грунта. Также есть случаи, когда структурные свойства материала необходимо изменить в середине этапа, как например твердение бетона обделки или изменение толщины обделки. В таких случаях свойства материалов заданных элементов могут быть изменены без ограничения числа таких операций. Измененные свойства материалов учитывают в расчете элементные результаты (перемещения, напряжения, деформации) предыдущего этапа. Предупреждение: Функцию преобразования свойств материала должна использоваться с осторожностью. Изменение свойств материала заполнения выемки в расчетах поэтапности строительства может быть моделировано с использованием только преобразования свойств, без активации или деактивации элементов. При этом напряженное состояние с предыдущего этапа задается на следующий этап, то есть преобразование свойств материала может привести к наблюдаемому по результатам расчета физически неадекватному поведению. Таким образом, для получения корректных результатов преобразование свойств материала должно выполняться на этапе, где происходит деактивация и реактивация элемента. Если новый элемент активирован, то внутренний элемент обладает естественными напряжениями, деформациями и переменной внутреннего состояния равной нулю. Undrained Analysis (Расчет для недренированных условий) Расчет для недренированных условий может быть выполнен для выбранных элементов и выбранных этапов строительства. Для возможности выполнения недренированного расчета должны быть выполнены два условия. Во-первых, параметр дренирования должен быть установлен как недренированный тип в модели материала. Во-вторых, условие недренирования должно быть активировано в настройках расчет этапа строительства. Если выполнено только одно условие, то для материала расчет в дренированных условиях выполняется на соответствующем этапе. Для одиночных расчетных случаев, таких как статический линейный/нелинейный расчет, или расчет устойчивости откоса, активируйте опцию Analysis Control (Настройки расчета) > Undrained Condition (Недренированные условия) > Allow Undrained Material Behavior (Разрешить недренированное поведение материала).
