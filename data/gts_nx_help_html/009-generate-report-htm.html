Generate report Home > GTS NX > Tools > Export > Generate Report Generate Report (Создание отчёта) - Обзор Пользователь может автоматически сгенерировать отчет Excel с актуальными данными. Существует четыре группы данных: изображение модели, изображение результата и результаты расчета НДС / фильтрации, при этом пользователь может организовать информацию в отчете от входных данных до результатов. В дополнение к результатам перемещений или напряжений по направлениям, результаты водопонижения, для получения которых ранее требовалось много усилий при формировании отчетов, отображаются в форме таблицы результатов и графика с помощью простого определения местоположения. - Методология Экспорт изображений модели и результатов расчёта (НДС/Фильтрация) в Excel <Создать отчёт> Функция «Создать отчет» генерируется на основе данных результатов расчёта. Это относится к категориям «Выходные данные», «Дополнительные настройки», «Выходной список». [ Output Data ] (Выходные данные): пользователь может выбрать каждый элемент, который необходимо сгенерировать. (При изменении типа расчёта, стадийности и результаты расчёта также изменяются в дополнительных настройках.) [ Sub Setting ] (Дополнительные настройки): изображения модели / изображения результата / результаты напряжений / результаты перемещений конструкции/водопонижение (2 D ) / значение притока, пользователь может контролировать, какой результат и последовательность строительства потребуются. [ Output List ] (Список вывода): имя отчета, путь вывода, добавление / изменение / удаление списка вывода (когда пользователь изменяет дополнительные настройки или выходные данные, необходимо нажать кнопку «Изменить», чтобы применить его.)
