Output Control Home > GTS NX > Analysis > Analysis Case > Output Control Output Control (Настойки вывода) ▒ Обзор Укажите тип вывода / опции вывода (система координат вывода результатов для элементов), а для динамического расчета – опцию вывода графика зависимости от времени. Результаты для узлов и элементов доступны по умолчанию в зависимости от типа расчета, кроме того в каждой колонке результатов могут быть избирательно указаны результаты для сохранения и выводы, что позволяет эффективно управлять размером файла результатов и временем вывода. ▒ Методология Можно вывести результаты для всех комплектов сеток, использованных в расчете, или выбрать только главный комплект сеток, требующий проверки результатов. Активируйте опцию [Результаты в углах элемента] (Element Corner Results) для вывода вычисленных результатов для каждого узла элемента напрямую в результатах для элементов. Деактивируйте данную опцию, для просмотра осредненных результатов в каждом узле. Шкала результатов формируется в соответствии с выбранной опцией просмотра результатов. Если необходимы результаты для оболочечных элементов в нейтральной плоскости, активируйте опцию [Результаты для срединной плоскости оболочки]. Для балочных элементов может быть настроено количество выводимых сегментов. Результаты могут быть представлены в точках 1(i, j), 2(i, 1/2, j), 3(i, 1/3, 2/3, j), 4(i, 1/4, 1/2, 3/4, j). Представленные результаты могут быть сохранены в отдельный текстовый файл в папке хранения модели.
