Devide set Home > GTS NX > Mesh > Mesh Set > Devide Set Devide Set (Разделение набора конечных элементов ) - Обзор Разделение наборов конечных элементов криволинейными и плоскими поверхностями. Элементы, которые попадают в плоскость разделения, будут автоматически перемещены в тот набор, который вмещает больший объем этого элемента. - Методология
