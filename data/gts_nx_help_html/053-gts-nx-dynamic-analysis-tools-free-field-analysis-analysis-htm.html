Analysis Home > GTS NX > Dynamic Analysis > Tools > Free Field Analysis > Analysis Analysis ( Расчет) - Обзор Создание расчетного случая. Добавление нового расчетного случая, редактирование, копирование, удаление существующего расчетного случая. Соответствующее диалоговое окно выглядит следующим образом: - Методология General (Общие данные) [Name] (Имя): Задайте имя расчетной модели. [Description] (Описание): Задайте описание расчетной модели. General Setting (Общие настройки) [Ground Material Set] (Задание материала основания): Выберите моделируемый слой для использования в расчете. [Depth No. of Bed Rock] (Заглубление подстилающей скалы): Укажите номер слоя, соответствующего положению подстилающей скалы. Control Motion Input (Настройки исходных колебаний) [Outcropping(2E)] (Внешняя граница (2E): Задание ускорений основания на внешней границе. [Within(E+F)] (Внутри (E+F)): Задание ускорений основания как отклика основания. [Depth No.] (Заглубление): Выберите контрольную точку для слоя, в котором задаются сейсмические колебания. [Ground Acceleration Function] (Функция ускорения основания): Выберите переменную во времени нагрузку, представляющую сейсмические ускорения. Water Level (Уровень воды) [No. of Water Level] (№ уровня воды): может быть выбран идентификатор слоя, введенный в поле "Грунтовый материал"; расчитывается исходя из того, что уровень воды существует в выбранном слое. Analysis (Расчет) [Cut-off Frequency] (Ограничение частоты): Задайте диапазон частот для расчета частот. [Frequency Step (for Transfer function)] (Шаг частоты (для передаточной функции)): Задайте шаг вычисления частоты для расчета передаточной функции. [Maximum Number of Iteration] (Максимальное число итераций): Задайте максимальное число итераций для нахождения величин свойств эквивалентного линейного материала. [Tolerance] (Допуск): Укажите значение допуска для модуля сдвига и коэффициента демпфирования, используемое для нахождения величин свойств эквивалентного линейного материала путем итеративных вычислений. [Effective strain coefficient] (Коэффициент эффективных деформаций): Задайте коэффициент, необходимый для вычисления эффективных деформаций сдвига на основе максимальных деформаций сдвига. Response spectrum (Спектр реакции) [Damping] (Демпфирование): Задайте коэффициент демпфирования для расчета спектра реакции. Free Freld Analysis(Starting) (Анализ свободного поля (Начальные сведения)) Model (Strata modeling) (Модель (Редактирование слоев основания)) Model(Dynamic Curve Function) (Модель (Функция динамической кривой)) Model(Ground acceleration function) (Модель (Функция ускорения основания)) Earthquake Response Spectrum (Спектр реакции для землетрясения) Result (Результат)
