Linear Static Analysis Home > GTS NX > Analysis > Analysis Case > General > Linear Static Analysis Solution Type (Тип решения) ▒ Linear Static Analysis (Линейный статический расчет) Выполнение линейного статического расчета предполагает наличие линейно-упругих свойств у скальных и нескальных грунтов основания, также расчет поведения основания при нагружении определяется статическим расчетом. Грунтовые материала проявляют линейно-упругие свойства только на ранних этапах нагружения соответствующих появлению малых деформаций. Однако, так как линейно-статический подход не предполагает наступление разрушения и линейно идеализирует соотношение напряжений и деформаций, то он широко используется для выполнения простых расчетов, таких как расчет распределения напряжений и поиск мест их концентраций при естественном напряженном состоянии основания. В широком смысле линейное поведение может рассматриваться как особая форма нелинейного поведения, но так как линейный расчет прост и интуитивен, то линейный статический расчет рассматривается как отдельный тип расчета. Линейный расчет, включая линейный динамический расчет, использует упругие характеристики поведения заданных в расчете материалов. Также нелинейное поведение элементов упругой связи (только растяжение, только сжатие и нелинейно-упругое поведение) или стержневых элементов игнорируется, и такие элементы рассматриваются в расчете как упругие тела. Таким образом, линейно-статический расчет удобно использовать для приближенных исследований поведения грунта, для расчетов начального состояния в этапах строительства или для расчетов обделок туннелей. Линейный статический расчет не требует выполнения пошаговых вычислений, таким образом, время выполнения расчета минимально. В GTS NX при выполнении статических расчетов учитывается поровое давление, также упругим материалам могут быть заданы дренированные и не-дренированные условия.
