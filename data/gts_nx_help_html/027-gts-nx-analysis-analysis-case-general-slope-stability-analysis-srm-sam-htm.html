Slope stability analysis (SRM/SAM) Home > GTS NX > Analysis > Analysis Case > General > Slope stability analysis (SRM/SAM) Solution Type (Тип решения) ▒ Slope stability analysis (SRM/SAM) (Расчет устойчивости откоса (Метод редукции/Метод анализа напряжений)) Расчет устойчивости откоса насыпи или котлована является одной из наиболее часто решаемых задач геотехники. Откос всегда обладает потенциальной энергией собственного веса из-за действия гравитации, и если внешние силы, такие как поровое давление воды, заданные нагрузки, землетрясение, волновое воздействие и т. п. действуют на откос, его устойчивость существенно снижается. Если внутренние касательные напряжения от собственного веса и внешних нагрузок превышают сдвиговую прочность грунта откоса, то может произойти обрушение откоса. Вычисление запаса надежности откоса против обрушения под действием касательных напряжений и сдвигающих сил называется расчетом устойчивости откоса. При расчетах в GTS NX могут быть использованы следующие методы расчетов устойчивости откосов. Метод редукции (SRM): нелинейный метод расчета путем снижения прочности в конечно-элементной модели Метод анализа напряжений (SAM): Метод основан на решении нелинейной конечно-элементной задачи с использованием теории предельного равновесия Strength Reduction Method (SRM) (Метод редукции (SRM)) Расчет устойчивости откоса с использованием метода конечных элементов представляет собой численный метод расчета, который вычисляет минимальный коэффициент безопасности и схему обрушения с учетом различных форм, нагрузок и граничных условий. В частности, метод редукции может быть использован для моделирования процесса обрушения без предварительных предположений о форме кривой обрушения (Griffith et. al. 1999; Matsui, 1990). Данный метод также может быть использован для решения трехмерных осесимметричных задач. Метод редукции заключается в постепенном снижении сдвиговой прочности и угла трения , до тех пор пока вычисления не перестанут сходиться — такой момент считается моментом обрушения откоса. Максимальный коэффициент снижения прочности в этот момент используется для вычисления минимального коэффициента безопасности откоса. Stress Analysis Method based on limit equilibrium theory (SAM) (Метод анализа напряжений с использованием теории предельного равновесия (SAM)) Данный метод сначала использует метод конечных элементов для расчетов напряженного состояния откоса, затем с использованием полученного решения коэффициент надежности для каждой виртуальной поверхности скольжения определяется на основе предположения о ее конфигурации с использованием теории предельного равновесия. Вычисленный таким образом минимальный коэффициент безопасности для различных поверхностей скольжения становится расчетным коэффициентом безопасности. Метод SAM может быть использован только в двухмерных задачах.
