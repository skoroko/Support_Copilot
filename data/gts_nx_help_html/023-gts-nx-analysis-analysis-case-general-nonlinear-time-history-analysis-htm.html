Nonlinear time history analysis Home > GTS NX > Analysis > Analysis Case > General > Nonlinear time history analysis Solution Type (Тип решения) ▒ Nonlinear time history analysis (Нелинейный нестационарный расчет) Нелинейности также могут быть учтены в нестационарном расчете оснований и сооружений. Подобно нелинейному статическому расчету, в расчете могут быть учтены все вместе или выборочно нелинейности материалов, геометрические нелинейности, нелинейности нагрузок и граничных условий. Вообще говоря, большинство материалов оснований проявляют нелинейности свойств, и таким образом, динамический отклик основания может быть точно смоделирован с помощью нелинейного нестационарного расчета. Water level (Уровень воды) Нелинейный нестационарный расчет используется для определения динамического отклика за относительно короткое время, поэтому положение уровня воды в динамических расчетах считается постоянным. Loading in Nonlinear time history analysis (Нагружения в нелинейном нестационарном расчете) В нелинейном нестационарном расчете могут быть использованы динамические нагрузки (нагрузки, переменные во времени). Define time step (Определение шага по времени) В нелинейном нестационарном расчете выполняется неявное интегрирование по времени. Поэтому, от величины шаг может зависеть точность расчета. В общем случае адекватная точность результатов может быть достигнута тогда, когда шаг по времени меньше 10% самого малого из учитываемых периодов. Использование больших шагов по времени приводит к появлению ошибок интегрирования по времени, а использование слишком малых шагов связано с необоснованно высокой вычислительной стоимостью расчетов. В нелинейном расчете сходящееся решение находится с помощью итеративных вычислений, и поэтому шаг по времени должен быть выбран аккуратно.
