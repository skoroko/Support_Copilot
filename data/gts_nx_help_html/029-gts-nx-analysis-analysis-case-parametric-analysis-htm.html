Parametric Analysis Home > GTS NX > Analysis > Analysis Case > Parametric Analysis Parametric Analysis (Параметрический расчет) ▒ Обзор Данная функция полезна для изменения свойств (материала) определенного элемента модели и выполнения сравнительного расчета. Типичный пример – расчет с использованием параметра Ко. Например, при выполнении расчетов туннеля с учетом поэтапности его проходки может быть выполнено сравнение результатов расчета для значений величины Ко 0.5, 1 и 1.5. Модель при этом не дублируется, расчеты выполняются для различных значений указанного свойства. Расчет может быть выполнен с учетом изменения различных условий, и не только материалов основание, но также структурных характеристик (характеристик сечения) с последующим сравнением результатов. ▒ Методология Во-первых, необходимо выбрать базовый расчетный случай. Параметрический расчет формируется автоматически путем задания условия изменения характеристик, как указано далее. Выберите целевой комплект сеток и укажите целевое свойство, эффект изменения которого необходимо исследовать (среди свойств выбранного элемента), и последовательно задайте значения данного свойства. Нажмите кнопку Add/Edit (Добавить/Редактировать) для создания параметрического расчетного случая.
