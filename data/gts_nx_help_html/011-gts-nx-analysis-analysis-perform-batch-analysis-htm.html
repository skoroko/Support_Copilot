Perform,Batch Analysis Home > GTS NX > Analysis > Analysis > Perform,Batch Analysis Perform/Batch Analysis (Выполнить расчет / Пакетный расчет) ▒ Обзор Выполните расчет для созданного расчетного случая. Если было создано несколько расчетных случаев, то выберите случаи, для которых необходимо выполнить расчет, и выполните комплект расчетов для одновременного сравнения нескольких моделей. ▒ Методология Выберите расчетные случаи для выполнения расчета. Пакетный расчет полезен при необходимости выполнения расчета для нескольких моделей. Во время расчета сходимость может контролироваться с помощью сообщений о предупреждениях и ошибках в окне вывода. После завершения расчета автоматически созданный текстовый файл в сохраненной папке может быть использован для просмотра результатов расчета, проверки сходимости и изучения предупреждающих сообщений, полученных в процессе выполнения расчета.
