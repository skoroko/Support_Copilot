Linear time history analysis (Modal/Direct) Home > GTS NX > Analysis > Analysis Case > General > Linear time history analysis (Modal/Direct) Solution Type (Тип решения) ▒ Linear time history analysis (Modal/Direct) (Линейный нестационарный расчет (Модальный/Прямой)) В линейном нестационарном расчете находится решение динамических уравнений равновесия для поведения сооружения (перемещения, усилия в элементах и т. д.) в произвольный момент времени с использованием динамических свойств сооружения и заданных нагрузок при заданной динамической нагрузке. Для выполнения линейного нестационарного расчета используется метод суперпозиции форм (Modal superposition method) и прямой метод (Direct method). Из-за концепции линейного расчета нелинейности в таком расчете не учитываются. При использовании нелинейных материалов выполняется преобразование материала в эквивалентный линейный упругий материал. В модели для линейного нестационарного расчета может быть задан уровень воды, а в результатах расчета — представлены эффективные напряжения. Также в расчете могут быть учтены дренированные/недренированные условия работы материалов. Mode superposition method (Метод суперпозиции форм) Метод суперпозиции форм предполагает определение перемещений сооружения в виде линейного сочетания ортогональных перемещений. В рамках данного подхода может быть использована упрощенная функция интегрирования по времени для вычисления динамического отклика для выбранной формы. Метод суперпозиции форм используется во многих программах расчета сооружений, и является эффективным ресурсосберегающим способом расчетов динамического отклика в линейных динамических расчетах больших сооружений. Однако точность расчета полной реакции зависит от числа используемых собственных форм, т. е. число используемых в расчете форм должно выбираться обоснованно. Direct method (Прямой метод) Прямой метод представляет собой нестационарный расчет, который использует степени свободы всей области расчета в качестве переменных. Уравнение динамического равновесия для полного набора степеней свободы может быть интегрировано по времени для нахождения решения. Решение находится для каждого этапа без внесения изменений в уравнение равновесия, при том могут быть использованы различные методы интегрирования. Методом прямого интегрирования выполняется расчет для всех временных этапов, число которых пропорционально расчетному времени. Loading in Linear time history analysis (Нагружения в линейном нестационарном расчете) В линейном нестационарном расчете могут быть использованы динамические нагрузки (нагрузки, переменные во времени). Define time step (Определение шага по времени) Шаг по времени в нестационарном расчете отличается для прямого и модального методов. Прямой метод использует заданный шаг по времени для выполнения неявного интегрирования по времени. Поэтому, от величины шаг может зависеть точность расчета. В общем случае адекватная точность результатов может быть достигнута тогда, когда шаг по времени меньше 10% самого малого из учитываемых периодов. Использование больших шагов по времени приводит к появлению ошибок интегрирования по времени, а использование слишком малых шагов связано с необоснованно высокой вычислительной стоимостью расчетов. В прямом методе интегрирование по времени выполняется аналитически. Поэтому шаг по времени не влияет на точность вычисленных результатов. Величина шага по времени модального метода используется для просмотра промежуточных результатов нестационарного расчета. Сравнение прямого и модального методов Прямой метод обычно требует больше вычислительных ресурсов, чем модальный метод. Поэтому, если для расчета необходимо много шагов по времени или размер модели велик, то более эффективным является использование модального метода. Если много собственных частот вычисляется близко к частоте нагрузки (например, в задаче присутствует слишком много активных частот), то лучше использовать прямой метод для получения более точных результатов.
