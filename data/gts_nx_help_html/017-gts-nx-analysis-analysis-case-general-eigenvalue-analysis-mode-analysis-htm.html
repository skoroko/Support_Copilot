Eigenvalue analysis (Mode analysis) Home > GTS NX > Analysis > Analysis Case > General > Eigenvalue analysis (Mode analysis) Solution Type (Тип решения) ▒ Eigenvalue analysis (Mode analysis) (Расчет собственных форм (Модальный расчет)) Расчет собственных форм используется для анализа динамических свойств основания/сооружения — собственных форм, собственных периодов (частот), коэффициентов участия форм и т. д. Эти свойства определяются массой и жесткостью сооружения. Другими словами, если определены параметры сооружения, то определены также его собственные частоты и формы колебаний, и число таких свойств соответствует числу степеней свободы сооружения. В реальных условиях сооружение колеблется не по единственной форме, а по сложной форме, образованной наложением многих форм колебаний. Коэффициент участия массы (Mass participation factor) представляет собой процентный коэффициент участия массы, который определяет степень участия конструкции в колебаниях по каждой форме колебаний, когда сооружение колеблется по сложной форме. Например, если коэффициент участия массы для первой формы равен 60%, это значит, что 60% общей массы сооружения участвует в первой форме. Таким образом, формы с высокими коэффициентами участия массы учитываются при расчетах сейсмических колебаний. Для большинства сооружений достаточную точность расчета обеспечивает учет только форм, сумма коэффициентов участия массы которых составляет около 90%. Однако, характеристики материалов основания относительно ниже характеристик сооружения, так что в расчете собственных форм сложно получить коэффициент участия массы в 90%. Периоды колебаний также относительно ниже, и специальные стандарты для этого случая отсутствуют. Собственные периоды определяются как время, необходимое сооружению для совершения колебания от естественного состояния до заданной формы с использованием собственного значения, которое 1:1 соответствует естественной форме. <Формы собственных колебаний> <Собственные частоты> Обобщенный критерий сейсмостойкого проектирования требует, чтобы в расчете были учтены формы, вовлекающие более 90% от всей массы сооружения. Такой подход позволяет учесть большинство главных форм колебаний, определяющих результаты расчета.
