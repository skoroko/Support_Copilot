Earthquake Response Spectrum Home > GTS NX > Dynamic Analysis > Tools > Free Field Analysis > Earthquake Response Spectrum Earthquake Response Spectrum (Спектр реакции землетрясения) ▒ Обзор Расчет и отображение графика спектра реакции землетрясения с использованием данных сейсмических колебаний из базы данных или пользовательских данных сейсмических колебаний. Задайте коэффициент демпфирования. Чтобы отобразить одновременно несколько графиков с разными значениями коэффициента демпфирования, нажмите кнопку [Добавить] (Add). Задайте диапазон периодов и шаг значений для построения графика. Выберите тип спектра. Активируйте опции [Лог. масштаб шкалы по оси X] (X-axis log scale) и [Лог. масштаб шкалы по оси Y] (Y-axis log scale) чтобы отобразить шкалы соответственно осиX и Y в логарифмическом масштабе. ▒ Методология Быстрое преобразование Фурье предлагает для удобства пользователя следующих 3 типа методов задания переменной во времени нагрузки: 1) Метод сохранения в виде файла и импорта часто используемой переменной во времени нагрузки 2) Метод вызова из базы данных переменной во времени нагрузки 3) Метод прямого задания данных пользователем Задание сейсмической нагрузки поддерживается только для величин, полученных делением истории ускорений на ускорение гравитации. 1. Method of saving the frequently used time varying load as a file and importing (Метод сохранения в виде файла и импорта часто используемой переменной во времени нагрузки) [Import] (Импорт) Используется для импорта переменной во времени нагрузки из сохраненного файла. Поддерживаемые форматы данных - *.sgs и *.thd, файлы которых имеют следующую структуру: *SGSw Данная строка указывает, что этот файл создан в формате данных модуля извлечения данных GTS NX “Seismic Data Generator” (Генератор сейсмических данных). *TITLE, Elcentro 1940, N-S Component - *X-AXIS, Second - *Y-AXIS, Normalized Acceleration - *UNIT&TYPE, GRAV, ACCEL - *FLAGS, 0, 0 - *DATA - 1.00000E-010, 3.50102E-001 - 5.00000E-002, 3.82861E-001 - 1.00000E-001, 5.08226E-001 - 1.50000E-001, 5.17459E-001 - : - <Таблица. Формат файла 'fn.sgs'> Избирательный элемент ** Аннотация может быть задана в любом месте - *UNIT, M , N - Length : MM, CM, M, INCH, FEET, GRAV 가능 *Load : KG, TON, KN, LBF, KIP - *TYPE, ACCEL - ACCEL, FORCE, MOMENT 가능 Необходимый элемент *Data ( Данные) - X1 , Y1 (X : Время , Y : Функция времени ) - X2 , Y2 - X3 , Y3 - : <Таблица. Формат файла 'fn.thd' file format –: Пользовательский ввод> 2. Method of calling up the time varying load from the GTS NX database (Метод вызова из базы данных переменной во времени нагрузки) [Earthquake wave] (Сейсмические колебания) Создание переменной во времени нагрузки путем импорта различных сейсмических данных из базы данных. В базе данных программы содержится всего 32 комплекта сейсмических данных. 3. Direct user input method (Метод прямого задания данных пользователем) Прямое создание переменной во времени нагрузки путем задания пар значений — времени и соответствующего значения нагрузки в соответствующей таблице в левой части диалогового окна.
