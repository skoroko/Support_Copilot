Model(Ground acceleration function) Home > GTS NX > Dynamic Analysis > Tools > Free Field Analysis > Model(Ground acceleration function) Model : Ground acceleration function (Модель: Функция ускорения основания) ▒ Обзор Задание переменной во времени нагрузки для расчета заданного основания на сейсмические воздействия. ▒ Методология Add/Modify/Delete Acceleration (Добавить/Редактировать/Удалить ускорение) Задание новых данных ускорений, или проверка, редактирование или удаление существующих данных. Function Name (Имя функции) Выбор заданного условия нестационарного расчета. Если условие не задано заранее, нажмите кнопку для вызова данной функции. Time function data type (Тип данных функции времени) [Normalized acceleration] (Нормализованное ускорение): Данный спектр определяется делением спектра ускорений на ускорение гравитации, при этом не может быть задан другой тип ускорения. [Acceleration] (Ускорение): Спектр ускорений с учетом времени. Scaling (Масштабирование) Задайте модуль градиента для функции ускорения основания. [Scale factor] (Масштабный коэффициент): Задайте модуль градиента. [Maximum value] (Максимальная величина): Изменение спектральных данных таким образом, что максимальное ускорение становится равным заданному значению. Gravity (Гравитация) Задайте ускорение гравитации. Graph Options (Опции графика) Укажите, необходимо ли представлять оси графика в логарифмическом масштабе. [x-axis log scale] (Логарифмический масштаб шкалы по оси х) Укажите, необходимо ли представлять ось х графика в логарифмическом масштабе. [y-axis log scale] (Логарифмический масштаб шкалы по оси y) Укажите, необходимо ли представлять ось y графика в логарифмическом масштабе. [F.F.T] (Быстрое преобразование Фурье) Укажите, необходимо ли применить к графику быстрое преобразование Фурье. Description (Описание) Отображение простого описания функции ускорения основания. Если использована функция [Землетрясение] (Earthquake), то используются величины максимального ускорения и времени для создания отображаемой волны. Export (Экспорт) Экспорт функции ускорений основания в виде текстового файла (*.txt).
