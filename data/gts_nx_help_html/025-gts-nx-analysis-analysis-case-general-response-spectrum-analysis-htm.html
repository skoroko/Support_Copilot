Response Spectrum Analysis Home > GTS NX > Analysis > Analysis Case > General > Response Spectrum Analysis Solution Type (Тип решения) ▒ Response Spectrum Analysis (Линейно-спектральный расчет (Расчет спектра реакции)) Расчет спектра реакции использует для суммирования спектральные данные, соответствующие абсолютным максимальным значениям времени реакции для каждой формы с использованием принципа суперпозиции. Так как одновременность появления максимальной величины для каждой формы не учитывается, и суммируются только абсолютные максимальные величины, то такой подход считается адекватным решением модальной линейной нестационарной задачи. Кроме того, корреляция между формами колебаний учитывается при суммировании форм колебаний для коррекции ошибки одновременности. Spectrum data (Спектральные данные) Спектральные данные представляют собой величины абсолютных максимумов перемещений (или скоростей, ускорений), найденных при фиксированном коэффициенте демпфирования и переменной величине периода (массы, жесткости) системы с единственном степенью свободы для данных во времени. Так как коэффициент демпфирования для каждой формы колебаний сооружения может быть разным, то вместо использования спектральных данных для одного коэффициента демпфирования, используется набор спектральных данных для различных коэффициентов демпфирования полученных путем интерполяции. Шаг периодов, используемый для создания спектральных данных, может отличаться от собственных периодов сооружения, то есть необходима интерполяция между величинами собственных периодов. Для этого поддерживается как линейная, так и логарифмическая интерполяция. Также для формирования спектральных данных чаще используется проектный спектр реакции созданный на основе статистической обработки данных землетрясений в целевом регионе, чем специально заданные данные. Так как обычно используется проектный спектр реакции с одним коэффициентом демпфирования, то при этом используется коррекция вместо интерполяции. <Создание спектра реакции перемещений системы SDOF> Damping consideration (Учет демпфирования) Учет демпфирования необходим для точности динамического расчета. Все реальные сооружения не могут колебаться бесконечно, так как происходят потери энергии на молекулярном уровне, либо энергия в сооружении теряется за счет взаимодействия элементов сооружения, которое приводит к демпфированию и постепенному затуханию колебаний сооружения. В частности, в случае возбуждения в области близкой к собственной частоте сооружения (эффект резонанса) демпфирования оказывает преобладающее влияние на результаты расчета. <Без учета демпфирования> <С учетом демпфирования> Точное значение коэффициента демпфирования сооружения должно определяться экспериментально; обычно используемые значения коэффициента демпфирования приведены ниже. Система Коэффициент демпфирования Стальная конструкция (в пределах упругой области) < 1 % Стальная конструкция с шарниром 3 % ~ 7 % Трубная система малых диаметров 1 % ~ 2 % Трубная система больших диаметров 2 % ~ 3 % Резиновый материал ~ 5 % Преднапряженное бетонное сооружение 2 % ~ 3 % Железобетонное сооружение 4 % ~ 7 % Модальное демпфирование чаще всего используется для учета структурного демпфирования в общих численных расчетах. При модальном методе учета демпфирования демпфирование определяется для каждой собственной частоты в системе и может быть подразделено на пропорциональное и непропорциональное демпфирование. Пропорциональное демпфирование может быть пропорционального массе типа, пропорционального жесткости типа или Рэлеевским типом демпфирования. Масс-пропорциональное демпфирование выражает собой вязкостное демпфирование вследствие таких внешних факторов, как сопротивление воздуха, и считается, что матрица демпфирования пропорциональна массе. Для жесткость-пропорционального демпфирования демпфирующий эффект рассеяния (энергия колебаний рассеивается в основание) сложно выразить напрямую и считается, что он пропорционален демпфирующей жесткости. Таким образом, демпфирование может быть переоценено для высших форм колебаний. Рэлеевское демпфирование является жесткость-пропорциональным типом демпфирования скорректированным на постоянное демпфирование для высших форм, и может быть выражено в виде суммы масс-пропорционального и жесткость-пропорционального типов демпфирования.
