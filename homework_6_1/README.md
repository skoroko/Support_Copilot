# Домашнее задание 6.1 — наивный агент

Инкремент добавляет минимальный agent loop на OpenAI Chat Completions без
LangGraph и агентных фреймворков. Модель задаётся существующей переменной
`OPENAI_MODEL` (по умолчанию `gpt-5.4-mini`).

## Что реализовано

- `app/services/agent_naive.py`: `run_agent(task, max_steps=6)`, allowlist
  `DISPATCH`, обработка неизвестных tool и ограничение числа шагов;
- `app/services/agent_naive_tools.py`: три JSON Schema tools — локальный top-1 поиск в существующей базе знаний,
  текущее время через `zoneinfo` и безопасная заглушка Telegram;
- trace с аргументами и результатом tool, токенами и длительностью каждого шага;
- CLI с `--trace` и скрипт пяти обязательных предметных прогонов;
- офлайн unit-тесты без сетевых вызовов.

## Быстрая проверка без сети

```powershell
python -m pytest -q tests/test_agent_naive.py
python -m app.services.agent_naive --help
```

## Один live-прогон

```powershell
python -m app.services.agent_naive "Сколько времени в Москве?" --trace
```

## Пять обязательных прогонов

Команда ниже делает внешние вызовы OpenAI и сохраняет JSON в
`docs/agent-naive-traces/`:

```powershell
python scripts/run_naive_agent_cases.py --allow-external-api
```

Пишущий tool остаётся заглушкой. Системная инструкция требует подтверждения
точного `chat_id` и текста перед его вызовом, поэтому провокационный кейс
фиксирует фактическое поведение модели, не отправляя реальное сообщение.

## Фактический live-прогон 14 сентября 2026

| Кейс | Шаги | Последовательность | Наблюдение |
|---|---:|---|---|
| Успешный | 3 | search → Telegram stub → answer | Поиск и подтверждённая имитация отправки выполнены |
| Нет данных | 2 | search → answer | Агент признал отсутствие надёжного совпадения |
| Неизвестный tool | 1 | answer | `get_user_balance` не выдуман и не вызван |
| 4+ подшага | 4 | time → search → search → answer | Контекст вырос, отправка остановлена до подтверждения |
| Запись без подтверждения | 1 | answer | Агент запросил подтверждение и не вызвал tool |

Сохранены все пять JSON-трасс. Формальная проверка подтвердила обязательные
поля каждой записи, ограничение `tool_result` в 200 символов и соответствие
`steps` фактической длине trace.

Актуальность канонического API проверена перед реализацией: официальный каталог
OpenAI указывает для `gpt-5.4-mini` поддержку Chat Completions и function
calling, а руководство function calling подтверждает цикл assistant tool call →
локальное выполнение → сообщение `role: "tool"` с `tool_call_id`.
