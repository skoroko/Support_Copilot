## Summary

Adds the isolated homework 6.5 experiment that compares a single LangChain
agent with a manual LangGraph supervisor composed of `researcher` and `writer`.
Both implementations use the same five questions, model configuration and
mock `search_knowledge_base` tool. The checked-in results are from the
user-approved live run and include agent usage, latency, handoffs and one
separately accounted batched LLM judge call.

## Behavioral details

- External provider calls require the explicit `--allow-external-api` flag.
- The supervisor route is bounded and deterministic:
  `START -> supervisor -> researcher -> supervisor -> writer -> END`.
- The writer receives no tools and must compose a cited answer from the
  researcher packet.
- The single-agent baseline uses the exact same retrieval tool and cases.
- Provider error details and configuration secrets are not persisted.
- Judge usage is recorded separately and excluded from the agent comparison.

## Measured result and decision

- Single-agent: 1100.2 average tokens, 2 model calls, 2248.48 ms p50, quality
  5.0/5 and zero handoffs.
- Multi-agent: 1470.2 average tokens, 3 model calls, 3987.97 ms p50, quality
  3.0/5 and three handoffs.
- Multi-agent used 33.63% more tokens and had 77.36% higher p50 latency while
  scoring two quality points lower.
- Decision: keep the single-agent tool architecture as the default diploma
  agent layer. The multi-agent prototype remains isolated in `experiments/`;
  no `app/agents/` production package is introduced.

## Remaining risks

- The evaluation contains only five synthetic cases and one model-judge run;
  it supports the current narrow decision but not a universal claim about
  multi-agent systems.
- Two multi-agent answers incorrectly used the out-of-base fallback. The
  recorded data proves the behavior but does not retain enough intermediate
  detail to attribute it to prompting, retrieval query choice or context
  transfer.
- `InMemorySaver` is appropriate for the experiment and is not durable
  production persistence.
- The architecture map reported one pre-existing boundary violation between
  `scripts/bench_agents` and `scripts/run_agent_comparison`; the HW 6.5 modules
  introduced no new reported violation.
